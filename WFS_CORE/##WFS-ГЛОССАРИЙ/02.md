## СХЕМА АРХЕТИПОВ ПО УРОВНЮ АКТИВНОСТИ от BIO-LOGIC:

| Уровень | Архетипы | Характер |
|---------|----------|----------|
| **0. Полный паралич** | **Тюфяк** | Не действует. Среда для остальных. |
| **1. Скрытый паралич** | **Кисель**, **Страус** | Маскируют бездействие. |
| **2. Полу-активность (защита)** | **Фазан**, **Зануда**, **Сова** | Активны в шуме, оправданиях, деталях. |
| **3. Активность через страх** | **Сквозняк** | Активен в генерации угроз. |
| **4. Активность через повтор** | **Крот** | Активен в ригидности. |
| **5. Активность через суету** | **Малявка** | Активен в имитации. |
| **6. Активность через воровство** | **Скряга**, **Зука** | Активны в обесценивании и обиде. |
| **7. Активность через силу** | **Кулак** | Грубая, примитивная. |
| **8. Активность через доминацию** | **Баклажан**, **Братишка** | Давление, панибратство. |
| **9. Активность через манипуляцию** | **Авантюрист** | Ложь, риск, вовлечение других. |
| **10. Активность через хаос** | **Фраер** | Иррациональные данные, распад. |

**Принцип:** чем выше активность, тем больше архетип **вовлекает других** в свой каскад. Тюфяк парализует всех, 

кто рядом. Фраер разрушает систему целиком.
