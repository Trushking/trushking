## 1. Архитектура видео (3–5 минут)

**Единый шаблон для всех работ:**

**Шаг 3. Запись голоса (15 мин).** Твой голос. Без музыки на фоне. Спокойно, размеренно.

**Шаг 4. Монтаж (1 час).** Простой: слайды + голос + субтитры. Никаких эффектов.
