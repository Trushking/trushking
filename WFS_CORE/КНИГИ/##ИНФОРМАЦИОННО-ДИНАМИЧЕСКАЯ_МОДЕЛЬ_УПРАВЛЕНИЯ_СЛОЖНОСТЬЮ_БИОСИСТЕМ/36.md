## Глава 32. Единая термодинамическая формализация: связь уравнения ICFT с теориями Пригожина и Ландау

### 32.1. Исходное уравнение ICFT

Базовое уравнение динамики энтропии биосистемы в поле ICFT:

\begin{equation}
\frac{dH}{dt} = \alpha\bigl(1 - C(t)\bigr) - \beta\, C(t) + \xi(t)
\label{eq:ICFT}
\end{equation}

где \(H\) — энтропия системы, \(C \in [0,1]\) — когерентность внимания (параметр порядка), \(\alpha\) — коэффициент генерации энтропии при \(C=0\), \(\beta\) — коэффициент диссипации энтропии при \(C=1\), \(\xi(t)\) — стохастический член.

Перегруппируем:

\begin{equation}
\frac{dH}{dt} = \alpha - (\alpha + \beta)\, C(t) + \xi(t)
\label{eq:ICFT_rearranged}
\end{equation}

Введём критическое значение когерентности:

\begin{equation}
C^* = \frac{\alpha}{\alpha + \beta}
\label{eq:Ccrit}
\end{equation}

Тогда уравнение \eqref{eq:ICFT_rearranged} принимает вид:

\begin{equation}
\frac{dH}{dt} = -(\alpha + \beta)\bigl(C - C^*\bigr) + \xi(t)
\label{eq:ICFT_linear}
\end{equation}

Уравнение \eqref{eq:ICFT_linear} линейно по \(C\). При \(C > C^*\) энтропия убывает (\(dH/dt < 0\)), при \(C < C^*\) — растёт.

---

### 32.2. Декомпозиция Пригожина

В термодинамике неравновесных процессов Пригожин ввёл разложение полного изменения энтропии на две составляющие:

\begin{equation}
dS = d_e S + d_i S
\label{eq:Prigogine_decomp}
\end{equation}

где \(d_e S\) — поток энтропии из среды (может быть отрицательным), \(d_i S\) — внутреннее производство энтропии (всегда \(d_i S \geq 0\) в силу второго начала).

Для системы ICFT отождествим:

\begin{align}
\frac{d_i H}{dt} &= \alpha\bigl(1 - C\bigr) + \beta\, C \;\geq\; 0 \label{eq:internal_production} \\[6pt]
\frac{d_e H}{dt} &= -2\beta\, C \;\leq\; 0 \label{eq:external_flow}
\end{align}

Тогда полное изменение:

\begin{equation}
\frac{dH}{dt} = \frac{d_i H}{dt} + \frac{d_e H}{dt} + \xi = \alpha(1-C) + \beta C - 2\beta C + \xi = \alpha(1-C) - \beta C + \xi
\end{equation}

что совпадает с \eqref{eq:ICFT}. 

**Физический смысл.** Внутреннее производство энтропии \(d_i H/dt = \alpha(1-C) + \beta C\) всегда положительно. Внешний поток \(d_e H/dt = -2\beta C\) отрицателен при \(C > 0\). Отрицательный поток означает **импорт негэнтропии** из Ψ-поля. Именно этот член обеспечивает локальное снижение энтропии без нарушения второго начала: рост энтропии в среде компенсирует её убыль в биосистеме.

### 32.3. Критерий эволюции Пригожина

Общий критерий эволюции Пригожина для систем, далёких от равновесия:

\begin{equation}
\frac{d_X \sigma}{dt} \leq 0
\label{eq:Prigogine_evolution}
\end{equation}

где \(\sigma = d_i S/dt\) — скорость производства энтропии, \(d_X \sigma\) — изменение производства, обусловленное изменением термодинамических сил при фиксированных потоках.

В формализме ICFT термодинамическая сила — это градиент когерентности \(\nabla C\), а поток — \(J = -D(C)\,\nabla C\). Тогда:

\begin{equation}
\sigma = \int_V D(C)\, \bigl(\nabla C\bigr)^2 \, dV \;\geq\; 0
\label{eq:sigma_ICFT}
\end{equation}

Критерий \eqref{eq:Prigogine_evolution} означает: система эволюционирует в направлении **минимизации производства энтропии** при заданных граничных условиях. В ICFT это соответствует росту \(C\) (снижению фрагментации внимания). При достижении порога \(C > C^*\) система переходит в новый диссипативный режим — режим регенерации.

### 32.4. Формализм Ландау

В теории фазовых переходов Ландау вводится параметр порядка \(\eta\) и функционал свободной энергии:

\begin{equation}
F(\eta) = F_0 + \frac{a}{2}\,\eta^2 + \frac{b}{4}\,\eta^4 - h\,\eta
\label{eq:Landau_F}
\end{equation}

где \(a = a_0(T - T_c)\) — управляющий параметр, меняющий знак в точке перехода, \(b > 0\) — коэффициент нелинейности, \(h\) — внешнее поле.

Динамика параметра порядка описывается уравнением Гинзбурга–Ландау (модель A):

\begin{equation}
\frac{\partial \eta}{\partial t} = -\Gamma\,\frac{\delta F}{\delta \eta} + \xi_\eta(t) = -\Gamma\bigl(a\,\eta + b\,\eta^3 - h\bigr) + \xi_\eta(t)
\label{eq:GL}
\end{equation}

В ICFT роль параметра порядка играет когерентность \(C\). Управляющий параметр \(a\) определяется балансом генерации и диссипации энтропии:

\begin{equation}
a = a_0\,(\alpha - \beta) = a_0\,(\alpha + \beta)\,\frac{\alpha - \beta}{\alpha + \beta} = a_0\,(\alpha + \beta)\,r
\label{eq:a_ICFT}
\end{equation}

где \(r = (\alpha - \beta)/(\alpha + \beta)\) — приведённый управляющий параметр. Критическая точка соответствует \(r = 0\), т.е. \(\alpha = \beta\).

Свободная энергия ICFT:

\begin{equation}
F(C) = \frac{a_0(\alpha - \beta)}{2}\,C^2 + \frac{b}{4}\,C^4 - h\,C
\label{eq:F_ICFT}
\end{equation}

Уравнение Гинзбурга–Ландау для \(C\):

\begin{equation}
\frac{dC}{dt} = -\Gamma\Bigl[a_0(\alpha - \beta)\,C + b\,C^3 - h\Bigr] + \xi_C(t)
\label{eq:GL_C}
\end{equation}

При \(\alpha > \beta\) (материалистическая парадигма, высокая энтропия) минимум \(F\) соответствует \(C \approx 0\) — фрагментированное внимание. При \(\alpha < \beta\) (парадигма #WFS, низкая энтропия) минимум смещается к \(C \approx 1\) — когерентное внимание.

---

### 32.5. Связанная система уравнений

Объединяя уравнение Гинзбурга–Ландау для \(C\) \eqref{eq:GL_C} и уравнение Пригожина для \(H\) \eqref{eq:ICFT}, получаем **связанную систему**:

\begin{equation}
\boxed{
\begin{aligned}
\frac{dC}{dt} &= -\Gamma\Bigl[a_0(\alpha - \beta)\,C + b\,C^3 - h\Bigr] + \xi_C(t) \\[8pt]
\frac{dH}{dt} &= \alpha\bigl(1 - C\bigr) - \beta\, C + \xi_H(t)
\end{aligned}}
\label{eq:coupled}
\end{equation}

**Интерпретация:**

- Первое уравнение описывает **динамику параметра порядка** \(C\) (когерентности внимания). Оно определяет, в каком аттракторе находится система: фрагментация (\(C \approx 0\)) или когерентность (\(C \approx 1\)).
- Второе уравнение описывает **отклик энтропии** \(H\) на текущее значение \(C\). Энтропия не является независимой переменной: она следует за параметром порядка.

**Стационарные состояния:**

При \(dC/dt = 0\) и \(\xi_C = 0\):

\begin{equation}
a_0(\alpha - \beta)\,C + b\,C^3 = h
\label{eq:stationary_C}
\end{equation}

При \(dH/dt = 0\) и \(\xi_H = 0\):

\begin{equation}
C^* = \frac{\alpha}{\alpha + \beta}
\label{eq:stationary_H}
\end{equation}

Условие устойчивой регенерации: \(C > C^*\). Это означает, что когерентность внимания должна превышать порог, определяемый балансом генерации и диссипации энтропии.

---

### 32.6. Единое уравнение

Подставим стационарное значение \(C^*\) в уравнение Гинзбурга–Ландау \eqref{eq:GL_C} в отсутствие шума:

\begin{equation}
0 = -\Gamma\Bigl[a_0(\alpha - \beta)\,C^* + b\,(C^*)^3 - h\Bigr]
\label{eq:unified_1}
\end{equation}

Отсюда внешнее поле \(h\), необходимое для поддержания \(C^*\):

\begin{equation}
h = a_0(\alpha - \beta)\,C^* + b\,(C^*)^3
\label{eq:h_ICFT}
\end{equation}

Подставляя \(C^* = \alpha/(\alpha+\beta)\):

\begin{equation}
h = a_0(\alpha - \beta)\,\frac{\alpha}{\alpha+\beta} + b\,\left(\frac{\alpha}{\alpha+\beta}\right)^3
\label{eq:h_final}
\end{equation}

Это соотношение связывает **внешнее воздействие** (поле \(h\), в роли которого выступает практика #WFS, парампара, резонансное взаимодействие) с **параметрами системы** (\(\alpha\), \(\beta\)) и **нелинейностью** (\(b\)).

**Единое уравнение ICFT–Пригожина–Ландау:**

\begin{equation}
\boxed{
\frac{dH}{dt} = -(\alpha + \beta)\left(C - C^*\right) + \xi(t), \qquad
\frac{dC}{dt} = -\Gamma\,\frac{\delta F}{\delta C} + \xi_C(t)
}
\label{eq:unified}
\end{equation}

где

\begin{equation}
F(C) = \frac{a_0(\alpha - \beta)}{2}\,C^2 + \frac{b}{4}\,C^4 - h\,C
\end{equation}

---

### 32.7. Физический смысл

1. **Пригожин.** Уравнение ICFT является частным случаем баланса энтропии Пригожина: \(dH/dt = d_iH/dt + d_eH/dt\). Внутреннее производство \(\sigma = \alpha(1-C) + \beta C \geq 0\) всегда положительно. Внешний поток \(d_eH/dt = -2\beta C\) отрицателен при \(C > 0\) и представляет собой **импорт негэнтропии** из Ψ-поля.

2. **Ландау.** Когерентность \(C\) играет роль параметра порядка. Управляющий параметр \(a = a_0(\alpha - \beta)\) меняет знак в критической точке \(\alpha = \beta\). При \(\alpha > \beta\) устойчивое состояние — \(C \approx 0\) (фрагментация). При \(\alpha < \beta\) — \(C \approx 1\) (когерентность). Переход между состояниями — фазовый переход второго рода.

3. **Связь.** Уравнение ICFT не заменяет теории Пригожина и Ландау. Оно **встраивается** в них, конкретизируя:
   - источник негэнтропии (Ψ-поле, доступное через \(C\));
   - управляющий параметр (\(r = (\alpha - \beta)/(\alpha + \beta)\));
   - механизм перехода (фазовый переход при \(C > C^*\)).

4. **Предсказание.** При достижении \(C > C^*\) система переходит в режим устойчивого снижения энтропии. Это фазовый переход, а не чудо. Регенерация — следствие диссипативной самоорганизации в открытой системе, обменивающейся информацией с Ψ-полем.

### 32.8. Сводная таблица соответствий

| Формализм | Параметр порядка | Управляющий параметр | Критическое условие | Роль внешнего поля |
|-----------|------------------|----------------------|---------------------|-------------------|
| **Пригожин** | \(C\) (когерентность) | \(\sigma = d_iH/dt\) | \(\sigma \to \min\) | Поток негэнтропии \(d_eH/dt\) |
| **Ландау** | \(C\) | \(a = a_0(\alpha - \beta)\) | \(a = 0 \Leftrightarrow \alpha = \beta\) | \(h\) (практика, парампара) |
| **ICFT** | \(C\) | \(r = (\alpha - \beta)/(\alpha + \beta)\) | \(C^* = \alpha/(\alpha + \beta)\) | Ψ-поле, резонанс |

---

### 32.9. Вывод

Уравнение ICFT \(dH/dt = \alpha(1-C) - \beta C + \xi\) является **частным случаем** термодинамики неравновесных процессов Пригожина и **согласуется** с теорией фазовых переходов Ландау. Связь формализована в виде системы \eqref{eq:coupled} и единого уравнения \eqref{eq:unified}. Это делает ICFT не альтернативой существующим физическим теориям, а их **расширением**, конкретизирующим источник негэнтропии и механизм управления энтропией биосистем через когерентность внимания.
