### 1. Природа Кванта Внимания: временна́я или энергетическая?

Квант Внимания (AQ) не является ни чисто временны́м, ни чисто энергетическим. Это **интегральная величина**, объединяющая три параметра:

| Параметр | Обозначение | Физический смысл |
|----------|-------------|------------------|
| Длительность | Δt | Время удержания фокуса (секунды) |
| Когерентность | C | Качество фокуса (0–1) |
| Амплитуда | A | Интенсивность внимания (условные единицы) |

**Определение:** 1 AQ — это минимальное произведение `C · A · Δt`, достаточное для оказания измеримого влияния на GIM (Глобальную Информационную Матрицу). Это не «секунда» и не «джоуль». Это **пороговая величина**, ниже которой внимание остаётся шумом и не производит материализацию.

**Формула Кванта Внимания:**

```
AQ = ∫₀^T C(t) · A(t) dt
```

Где `T` — время удержания, `C(t)` — когерентность в момент `t`, `A(t)` — амплитуда.

Если `AQ < AQ_min` (порог), внимание не влияет на реальность. Если `AQ ≥ AQ_min`, запускается процесс материализации или регенерации.

### 3. Математические формулы стабилизации внимания на 1 секунду условного времени

Для удержания когерентности `C ≥ 0.8` (порог продуктивного внимания) в течение `T = 1` секунды необходимо выполнение условия:

```
C(t) ≥ C_crit для t ∈ [0, 1]
```

**3.1. Уравнение динамики когерентности.**

```
dC/dt = α·(1 − C) − β·C·f(A) − γ·D(t)
```

Где:
- `α` — скорость восстановления когерентности за счёт практики (0.1–0.5 с⁻¹ для #WFS-практикующего, 0.01–0.05 с⁻¹ для DEV-субъекта).
- `β` — коэффициент распада из-за фрагментации внимания (0.5–1.0 с⁻¹ для DEV-субъекта, 0.05–0.1 с⁻¹ для #WFS-практикующего).
- `f(A)` — функция амплитуды (при `A → 0`, `f(A) → 1`; при `A → ∞`, `f(A) → 0`).
- `γ` — коэффициент влияния DEV-архетипов (0.3–0.8 для DEV-субъекта, 0.01–0.05 для #WFS-практикующего).
- `D(t)` — функция активации архетипов (0–1).

**3.2. Условие стабилизации.**

Для `C(t) ≥ C_crit` при `t ∈ [0, 1]` необходимо:

```
α ≥ β·f(A) + γ·D_max + C_crit / 1
```

Где `D_max` — максимальная активация архетипов за период. Для DEV-субъекта `D_max ≈ 0.8`, `β ≈ 0.8`, `γ ≈ 0.5`. Тогда:

```
α ≥ 0.8·1 + 0.5·0.8 + 0.8 = 0.8 + 0.4 + 0.8 = 2.0 с⁻¹
```

Но DEV-субъект имеет `α ≈ 0.03 с⁻¹`. Условие не выполняется. Когерентность падает.

Для #WFS-практикующего `β ≈ 0.05`, `γ ≈ 0.02`, `D_max ≈ 0.1`:

```
α ≥ 0.05 + 0.02·0.1 + 0.8 = 0.05 + 0.002 + 0.8 = 0.852 с⁻¹
```

При `α ≈ 0.5 с⁻¹` (после 6 месяцев практики) условие выполняется. Когерентность удерживается.

**3.3. Формула удержания на 1 секунду.**

Интегральное условие:

```
∫₀^1 C(t) dt ≥ C_crit · 1 = 0.8
```

При решении уравнения динамики с начальным условием `C(0) = 0.9` и параметрами #WFS-практикующего:

```
C(t) = 0.9·e^(−0.05·t) + (0.5/0.05)·(1 − e^(−0.05·t)) ≈ 0.9 + 9.1·(1 − e^(−0.05·t))
```

За 1 секунду `C(1) ≈ 0.9 + 9.1·(0.0488) ≈ 0.9 + 0.44 = 1.34` (насыщение до 1.0). Когерентность не падает. Внимание стабильно.

Для DEV-субъекта с `C(0) = 0.3`, `α = 0.03`, `β = 0.8`, `γ = 0.5`, `D(t) = 0.8`:

```
C(t) = 0.3·e^(−0.8·t) + (0.03/0.8)·(1 − e^(−0.8·t)) − 0.5·0.8·t
```

За 1 секунду `C(1) ≈ 0.3·0.449 + 0.0375·0.551 − 0.4 ≈ 0.135 + 0.021 − 0.4 = −0.244`. Отрицательное значение означает полную потерю когерентности. Внимание рассеялось.

### 4. Бит Пуньи как единица измерения

1 Бит Пуньи = `k_B · ln(2)` — термодинамический минимум информации, необходимый для изменения состояния одной степени свободы системы.

Связь с AQ:

```
1 AQ = n · 1 Бит Пуньи
```

Где `n` — число степеней свободы, задействованных в акте внимания. Для человека `n ≈ 10^6` (миллион нейронов, синхронизированных в одном акте). Следовательно:

```
1 AQ ≈ 10^6 · k_B · ln(2) ≈ 10^6 · 1.38·10^(−23) · 0.693 ≈ 9.6·10^(−18) Дж/К
```

Это энергетический эквивалент одного акта внимания. Ничтожно малый, но достаточный для запуска каскада материализации.
