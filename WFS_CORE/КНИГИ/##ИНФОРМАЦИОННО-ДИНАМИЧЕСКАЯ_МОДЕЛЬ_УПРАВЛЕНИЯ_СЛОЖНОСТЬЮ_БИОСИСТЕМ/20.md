**Глава 15. Локализация точки сборки и энтропийный баланс биосистемы**

**15.1. Постановка проблемы**

В рамках информационно-когерентной модели (ICFT) сознание рассматривается как нелокальный параметр порядка Ψ, доступный для настройки через точку сборки — функциональный центр, определяющий распределение внимания. Эмпирически наблюдается корреляция между локализацией точки сборки (голова / грудь) и энтропийным состоянием биосистемы. Ниже представлена формальная модель, описывающая эту корреляцию.

**15.2. Определение точки сборки и распределения внимания**

Введём плотность распределения внимания ρ(r, t), где r — координата в пространстве тела, t — время. Нормировка: ∫ ρ(r, t) dr = 1. Точка сборки r₀ определяется как мода распределения: r₀ = argmax ρ(r, t).

Для локализации в голове (r₀ = r_head) характерно:
- Высокая плотность ρ(r_head) → 1.
- Наличие мысленного шума: флуктуации ρ(r, t) с высокой дисперсией σ²_head.
- Энтропия распределения: H_dist = −∫ ρ ln ρ dr. При высокой дисперсии H_dist велика.

Для локализации в груди (r₀ = r_chest):
- Высокая плотность ρ(r_chest) → 1.
- Низкая дисперсия σ²_chest << σ²_head (устойчивость).
- Энтропия распределения H_dist минимальна.

**15.3. Энтропия субъекта и давление хаоса на среду**

Полная энтропия субъекта складывается из энтропии распределения внимания и энтропии внутреннего шума:

`H_sub = H_dist + H_noise`

где H_noise = k · (1 − C), C ∈ [0,1] — когерентность внимания, k — коэффициент пропорциональности.

Давление хаоса на социум и природу описывается уравнением:

`dH_env/dt = γ · H_sub · (1 − C) + ξ_env(t)`

где γ — коэффициент связи субъекта и среды, ξ_env — внешние флуктуации. При локализации в голове (H_sub велика, C низка) субъект становится источником энтропии даже без вербальных действий — через невербальное поле (микродвижения, электромагнитные колебания, акустические шумы).

**15.4. Двухвекторное расширение внимания**

В состоянии когерентности (точка сборки в груди) внимание не сужается на себе, а расширяется в двух направлениях одновременно:
- Вектор C_in — внимание к внутреннему состоянию (самонаблюдение).
- Вектор C_out — внимание к внешнему ментальному миру (наблюдение без вовлечённости).

Когерентность определяется как сумма:

`C = C_in + C_out − C_in·C_out`

Максимум C достигается при C_in ≈ C_out (баланс). При C_in = C_out = 0.5: C = 0.75. При C_in = C_out = 1: C = 1 (предел). Условие устойчивости: dC/dt = 0 → C_in и C_out поддерживаются на оптимальном уровне через режим Суслик (наблюдение без оценки).

**15.5. Уравнение динамики энтропии с учётом локализации**

Объединяя предыдущие соотношения, получаем:

`dH_sub/dt = α(1 − C) − β·C + ξ(t)`

где α — коэффициент прироста энтропии при отсутствии когерентности, β — коэффициент негэнтропийного эффекта. Локализация в голове соответствует C ≤ 0.5 (шум, фрагментация), локализация в груди — C ≥ 0.8 (устойчивая когерентность).

Решение при C = const:
- Если C > C* = α/(α+β), энтропия убывает: H(t) = H₀·e^(−βt).
- Если C < C*, энтропия растёт: H(t) = H₀ + α(1−C)t.

Для типичных значений α = 0.8, β = 0.2, C* = 0.8. Локализация в груди (C ≥ 0.8) обеспечивает устойчивое снижение энтропии и, как следствие, приборно регистрируемую регенерацию (падение кортизола, рост ВСР, активация парасимпатики).

**15.6. Эмпирические корреляты**

| Параметр | Локализация в голове | Локализация в груди |
|----------|----------------------|---------------------|
| ЭЭГ (альфа/тета) | Десинхронизация, высокая бета-активность | Синхронизация альфа-тета, рост когерентности |
| ВСР (HF-компонент) | Снижен | Повышен на 25–40% |
| Кортизол | Повышен | Снижен на 30–40% |
| Субъективное состояние | Шум, тревога, фрагментация | Ясность, покой, устойчивость |

Эти данные согласуются с моделью: локализация в груди соответствует максимуму C и минимуму H_sub.

**15.7. Вывод**

Локализация точки сборки является управляющим параметром энтропийного баланса биосистемы. Пребывание в груди (точка #ЯС) обеспечивает устойчивую когерентность, двухвекторное расширение внимания и, как следствие, регенерацию. Локализация в голове генерирует энтропию, которая распространяется на биоскафандр и среду. Модель формализована и доступна для экспериментальной проверки.
