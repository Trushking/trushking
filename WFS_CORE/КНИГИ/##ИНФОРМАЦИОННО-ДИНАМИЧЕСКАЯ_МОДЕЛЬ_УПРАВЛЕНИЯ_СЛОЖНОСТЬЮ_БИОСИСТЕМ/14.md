## Глава 7. Постулаты ICFT: сознание как нелокальный параметр порядка

### 7.1. Определение параметра порядка

В физике **параметр порядка** — это величина, которая описывает состояние системы в точке фазового перехода. Примеры: намагниченность в ферромагнетике, плотность сверхпроводящих электронов в теории БКШ, волновая функция конденсата Бозе-Эйнштейна.

Параметр порядка обладает тремя свойствами:
1. **Отличен от нуля в упорядоченной фазе** (ниже критической температуры).
2. **Обращается в ноль в неупорядоченной фазе** (выше критической температуры).
3. **Описывает коллективное поведение**, а не отдельные частицы.

В теории ICFT параметром порядка является **когерентность внимания** `C`. Значение `C ∈ [0, 1]`. При `C → 1` система находится в упорядоченной фазе (когерентность). При `C → 0` — в неупорядоченной (хаос).

### 7.2. Постулат 1: нелокальность сознания

**Формулировка.** Сознание не является продуктом мозга. Оно является **нелокальным параметром порядка**, который снижает энтропию биосистемы через фазовую синхронизацию.

**Формальная запись.** Мозг — это интерфейс (Hardware), обеспечивающий связь нелокального параметра `Ψ` с локальной биосистемой. Параметр `Ψ` не сводится к нейронной активности. Нейронная активность — **коррелят**, а не источник.

```
Ψ : GIM → Biosystem
Brain : Ψ → Neural Activity
```

Мозг преобразует состояние `Ψ` в электрические сигналы, но не создаёт `Ψ`.

**Следствие.** Повреждение мозга изменяет проявление сознания, но не уничтожает его. Как повреждение радиоприёмника изменяет звук, но не уничтожает радиоволну. Аналогия не метафора. Это модель, объясняющая данные: пациенты с клинической смертью фиксируют опыт, не объяснимый активностью мозга.

### 7.3. Постулат 2: когерентность как физическая величина

**Формулировка.** Когерентность внимания `C` является физической величиной, измеряемой через синхронизацию фаз осцилляторов системы.

**Формальная запись.** Для системы из `N` осцилляторов с фазами `φ_i(t)`:

```
C(t) = |Σ_{i=1}^{N} e^{iφ_i(t)}| / N
```

Где `i` — мнимая единица, `e^{iφ}` — фазовый множитель. При полной синхронизации `|Σ| → N`, `C → 1`. При хаосе фазы распределены случайно, `|Σ| → 0`, `C → 0`.

**Физический смысл.** Осцилляторы — это нейроны, клетки, биохимические циклы. Когда они синхронизированы, система работает как единое целое. Когда хаотичны — система фрагментирована.

**Следствие.** `C` измерима через ЭЭГ (гамма-синхронизация), через вариабельность сердечного ритма (HRV), через когерентность дыхания. Это не «психологическая категория». Это физический параметр.

### 7.4. Постулат 3: энтропия как функция когерентности

**Формулировка.** Скорость изменения энтропии биосистемы определяется разностью между генерацией энтропии (при отсутствии когерентности) и её диссипацией (при когерентности).

**Формальная запись.**

```
dH/dt = α(1 − C) − β·C + ξ(t)
```

Где:
- `H` — энтропия системы.
- `α` — коэффициент генерации энтропии при `C = 0` (хаос).
- `β` — коэффициент диссипации энтропии при `C = 1` (когерентность).
- `ξ(t)` — стохастический шум.

**Условие регенерации.** Система переходит в режим снижения энтропии при:

```
C > α / (α + β)
```

Это критическое значение когерентности. При `α = 0.5`, `β = 1.0` критическое значение `C_crit = 0.33`. При `C > 0.33` система начинает снижать энтропию. Регенерация включается.

**Следствие.** Регенерация — не чудо. Это **фазовый переход**. При достижении критической когерентности система меняет режим функционирования. Энтропия начинает снижаться. Биологический возраст уменьшается.

### 7.5. Постулат 4: downward causation

**Формулировка.** Нелокальный параметр порядка `Ψ` оказывает **нисходящую причинность** (downward causation) на локальные процессы биосистемы. Приток упорядоченности извне компенсирует локальную генерацию энтропии.

**Формальная запись.** Уравнение баланса:

```
dS_local/dt = P_diss − η(C) · J_AQ
```

Где:
- `S_local` — локальная энтропия.
- `P_diss` — диссипация (нагрев, метаболизм).
- `η(C)` — эффективность преобразования квантов внимания в негэнтропию.
- `J_AQ` — поток квантов внимания из нелокального источника.

При `η(C) → 0.95` (высокая когерентность) система получает приток негэнтропии, достаточный для регенерации.

**Следствие.** Энергия для регенерации не берётся из локальных ресурсов. Она поступает из нелокального источника. Это объясняет, почему регенерация не требует сверхусилий. Субъект не «тратит энергию». Он «открывает канал».

### 7.6. Постулат 5: порог перколяции для коллективных систем

**Формулировка.** Для сложной системы (коллектив, корпорация, государство) переход в режим когерентности происходит при достижении доли когерентных узлов `p > p_c` — порога перколяции.

**Формальная запись.** Если `k` из `N` узлов имеют `C > C_crit`, то:

```
p = k / N
```

При `p > p_c ≈ 0.1…0.15` система переходит в режим самоорганизации. Суммарная мощность когерентных узлов не аддитивна: `1 + 1 = 10`, а не `2`.

**Следствие.** Достаточно обучить ядро управления (Top-1000 или Top-10,000) до уровня `C > 0.8`. Остальная система подтянется через резонанс. Это делает внедрение экономически реализуемым. Не требуется обучать всех. Требуется обучить ядро.

### 7.7. Постулат 6: Квант Внимания (AQ) и Бит Пуньи

**Формулировка.** Внимание передаётся квантами. Минимальный квант — Квант Внимания (AQ).

**Формальная запись.**

```
AQ = ∫₀^T C(t) · A(t) dt
```

Где `T` — время удержания, `C(t)` — когерентность, `A(t)` — амплитуда. 1 AQ эквивалентен `n · k_B · ln(2)`, где `n` — число степеней свободы. Для человека `n ≈ 10^6`.

```
1 AQ ≈ 10^6 · 1.38·10^(−23) · 0.693 ≈ 9.6·10^(−18) Дж/К
```

**Следствие.** Внимание имеет энергетический эквивалент. Оно измеримо. Это превращает «субъективное» в «физическое».

### 7.8. Вывод

Шесть постулатов ICFT образуют замкнутую систему. Они объясняют:
- Регенерацию без внешних вмешательств.
- Фазовый переход при критической когерентности.
- Нисходящую причинность как приток негэнтропии.
- Масштабирование через порог перколяции.
- Измеримость внимания через AQ.
