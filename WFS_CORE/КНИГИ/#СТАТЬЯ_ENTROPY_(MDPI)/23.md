## ШАГ 2. Математическое ядро (дыры 13, 14, 15)

### Дыра 13. Порог C* для нелинейного уравнения

**Было:**
```
C* = α/(α+β)
```

**Стало:**
```
C*(H) = α / (α + βH)
```

Обоснование: стационарное состояние `dH/dt = 0`:
`α(1−C)H = βC·H²` → `α(1−C) = βC·H` → `C = α/(α+βH)`.

При H = 1: C* = 0.8 (совпадает с линейным случаем). При H = 0.5: C* = 0.89. При H = 0.1: C* = 0.976. Порог растёт при снижении энтропии — для дальнейшего снижения требуется всё большая когерентность.

### Дыра 14. Алгебраическая ошибка в перегруппировке

**Было (раздел 2.5):**
```
dH/dt = −(α+β)(C − C*)H + ξ(t)
```

**Стало:**
```
dH/dt = αH − (α+βH)C·H + ξ(t)
```
Перегруппировка в исходном виде возможна только при H = 1. В общем случае используем линеаризацию в окрестности стационарной точки `H* = α(1−C)/(βC)`. Для качественного анализа достаточно знать знак производной: при `C > C*(H)` имеем `dH/dt < 0`.

### Дыра 15. Уравнение для dΨ/dt

**Решение (Путь 1):** Ψ — статический конструкт, связь с H через `H = H_max − (H_max−H_min)|Ψ|²`. Динамика Ψ не вводится, чтобы не умножать сущности. Это признаётся ограничением и выносится в раздел «Ограничения».

**Решение (Путь 2, если рецензенты настаивают):** ввести феноменологическое уравнение релаксации:
```
dΨ/dt = −Γ · ∂F/∂Ψ + η(t)
```
где F — функционал свободной энергии, Γ — кинетический коэффициент, η — шум. Но это требует отдельной работы, выходящей за рамки статьи.
