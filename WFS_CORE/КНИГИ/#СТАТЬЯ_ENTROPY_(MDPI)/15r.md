### 1.3. ICFT как решение: теория единого поля сознания

Предлагается теория информационно-когерентного поля (ICFT). Сознание рассматривается как нелокальный параметр порядка Ψ, управляющий энтропией биосистем через когерентность внимания C. Основное уравнение:

```
dH/dt = α(1 − C)H − βC·H² + ξ(t)
```

где:
- `H` — энтропия биосистемы,
- `C ∈ [0,1]` — когерентность внимания (операционально измеримая величина),
- `α` — коэффициент прироста энтропии при отсутствии когерентности,
- `β` — коэффициент негэнтропийного эффекта,
- `ξ(t)` — стохастический член (внешние флуктуации).

Нелинейность (член `−βC·H²`) обеспечивает насыщение: при H → 0 рост замедляется, при H → ∞ ограничивается. Это снимает возражение о тривиальности линейной модели.

**Операциональное определение C:**
```
C = w₁·R̃MSSD + w₂·H̃F + w₃·S̃EEG + w₄·P̃subj
```
где:
- R̃MSSD — нормированный RMSSD (вариабельность сердечного ритма),
- H̃F — нормированный HF-компонент,
- S̃EEG — нормированная альфа-тета синхронизация ЭЭГ,
- P̃subj — нормированная субъективная шкала (0–10),
- wᵢ = 0.25 (первое приближение).

Нормировка: `R̃ = (R − R_min)/(R_max − R_min)`.

**Связь Ψ и H.** Ψ — комплексный параметр порядка (нелокальная мера когерентности поля), H — скалярная энтропия биосистемы. Связь:
```
H(t) = H_max − (H_max − H_min)·|Ψ(t)|²
```
При |Ψ| → 1, H → H_min. При |Ψ| → 0, H → H_max.

**Связь с Пригожиным.** Разложение `dS = d_eS + d_iS`, где `d_iS ≥ 0` (внутреннее производство энтропии), `d_eS` — внешний поток. Локальное снижение полной энтропии `dS < 0` достигается при `d_eS < −d_iS`. Роль отрицательного потока играет когерентность C.

**Связь с Ландау.** Перегруппировка уравнения:
```
dH/dt = −(α+β)(C − C*)H + ξ(t),  C* = α/(α+β)
```
При C > C* энтропия убывает. C* — критическое значение (аналог точки фазового перехода).
