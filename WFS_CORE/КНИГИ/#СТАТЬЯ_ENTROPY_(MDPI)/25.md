## ТЕОРЕТИЧЕСКОЕ ЯДРО ICFT (финальная версия)

### 1. Аксиоматика

**Аксиома 1 (информационное единство).** Всё сущее принадлежит единому полю GIM. Формально: `R ∈ GIM`. Посягательство на чужое (ложь, воровство, сокрытие) увеличивает энтропию: `Посягательство(R, S') → ΔH > 0`.

**Аксиома 2 (нелокальность сознания).** Сознание (Ψ) не является продуктом мозга. Мозг — интерфейс. Ψ — параметр порядка, доступный для настройки через когерентность внимания C.

**Аксиома 3 (когерентность).** Внимание — физическая величина, способная снижать энтропию биосистемы через резонансное взаимодействие с элементарными носителями информации (атомами внимания, Punon).

**Следствие (нелокальная ответственность).** Нет выделенного пространства. Каждое действие, слово, мысль изменяют энтропию поля.

### 2. Динамика Ψ (параметра порядка)

Ψ — комплексный параметр порядка с амплитудой |Ψ| (устойчивость, когерентность) и фазой φ (вибрационная настройка). Динамика:

```
d|Ψ|/dt = λ·C·|Ψ| − μ·|Ψ|³ + η(t)
dφ/dt = ω + ν·|Ψ|²
```

где:
- λ — коэффициент роста амплитуды при когерентности,
- μ — коэффициент насыщения (нелинейность),
- ω — собственная частота,
- ν — сдвиг частоты от амплитуды,
- η(t) — шум.

**Стационарная амплитуда:** `|Ψ|* = √(λC/μ)`. При C → 1: |Ψ|* → 1. При C → 0: |Ψ|* → 0.

**Связь с энтропией:**
```
H = H_max − (H_max − H_min)·|Ψ|²
```
При |Ψ| → 1: H → H_min. При |Ψ| → 0: H → H_max.

**Связь с качеством решений:** `Q ∝ |Ψ|²`. Цепочка: C → |Ψ| → H → Q → регенерация/экономика.

### 3. Динамика энтропии

Основное уравнение (нелинейное, логистическое):

```
dH/dt = α(1 − C)H − βC·H² + ξ(t)
```

где:
- H — энтропия биосистемы,
- C ∈ [0,1] — когерентность внимания,
- α — коэффициент прироста энтропии при C = 0,
- β — коэффициент негэнтропийного эффекта,
- ξ(t) — стохастический член.

**Стационарное состояние:** `H* = α(1−C)/(βC)` при ξ = 0.

**Порог когерентности (зависит от H):**
```
C*(H) = α / (α + βH)
```
При H = 1: C* = 0.8. При H = 0.5: C* = 0.89. При H = 0.1: C* = 0.976. При C > C*(H) энтропия убывает.

**Линеаризация в окрестности H*:** для качественного анализа знак производной определяется условием C > C*(H). Алгебраическая перегруппировка `dH/dt = −(α+β)(C−C*)H` верна только при H = 1 и не используется.

### 4. Связь с термодинамикой Пригожина

Разложение `dS = d_eS + d_iS`, где `d_iS ≥ 0` (внутреннее производство энтропии), `d_eS` — внешний поток. Локальное снижение `dS < 0` достигается при `d_eS < −d_iS`. Роль отрицательного потока играет когерентность C.

```
C = w₁·R̃MSSD + w₂·H̃F + w₃·S̃EEG + w₄·P̃subj
```

где:
- R̃MSSD — нормированный RMSSD (ВСР),
- H̃F — нормированный HF-компонент,
- S̃EEG — нормированная альфа-тета синхронизация ЭЭГ,
- P̃subj — нормированная субъективная шкала (0–10),
- wᵢ = 0.25 (первое приближение).

Нормировка: `R̃ = (R − R_min)/(R_max − R_min)`. Веса уточняются эмпирически.

```
#ИЗ = floor(10 / (1 + exp(-2.5 × (ln(ИЗ_сыр + 1) − 4.5))))
```
где:
```
ИЗ_сыр = (ИАОП × IH × SEI) / (ln(S̃ + 1) + 1)
```

### 7. Информационная дивергенция (замена ΔS = ΔQ/T)

```
ΔI = k · ΔQ · (−ln(1 − C))
```

где:
- ΔI — информационная дивергенция (мера «кармического» долга),
- ΔQ — потерянная энергия (нереализованный потенциал),
- C — когерентность,
- k — коэффициент пропорциональности.

При C → 1: −ln(1−C) → ∞ (малая ошибка даёт большой долг). При C → 0: −ln(1−C) → 0. Третье начало не нарушается.

**Накопленная дивергенция:**
```
I_cumulative = Σ (k·ΔQ_i·(−ln(1−C_i))) + ∫ ΔI_critical(t) dt
```
Критическая ошибка даёт скачок: `ΔI_critical = k_crit · ΔQ_critical`, где `k_crit >> 1`.

### 8. Информационная гигиена питания

```
ξ_food = −γ · H'_food
H'_food = H_food · (1 − C_offer)
```

где γ — коэффициент информационного вклада пищи. При C_offer → 1: H'_food → 0, ξ_food → 0. Первое приближение; для точного описания требуется отдельная модель.
