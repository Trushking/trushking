## ЧАСТЬ 2. ТЕОРЕТИЧЕСКАЯ ЧАСТЬ: ICFT

### 2.1. Аксиоматика

**#WFS-ЦМ-ТЕП-004 [ТИП: А]**
Аксиома информационного единства: всё сущее принадлежит единому полю (GIM). Формальная запись: `R ∈ GIM`. Посягательство на чужое (ложь, воровство, сокрытие) — операция, увеличивающая энтропию: `Посягательство(R, S') → ΔH > 0`.

**#WFS-ЦМ-ТЕП-005 [ТИП: А]**
Аксиома нелокальности сознания: сознание (Ψ) не является продуктом мозга. Мозг — интерфейс, а не источник. Ψ — параметр порядка, доступный для настройки через когерентность внимания (C).

**#WFS-ЦМ-ТЕП-006 [ТИП: А]**
Аксиома когерентности: внимание — физическая величина, способная снижать энтропию биосистемы через резонансное взаимодействие с элементарными носителями информации (атомами внимания, Punon).

**#WFS-ЦМ-ТЕП-056 [ТИП: А]**
Принцип нелокальной ответственности (следствие аксиом): нет выделенного пространства. Каждое действие, слово, мысль изменяют энтропию поля. Информационная безопасность — физическое требование, не моральная категория.

### 2.2. Основное уравнение динамики энтропии

**#WFS-ЦМ-ТЕП-007 [ТИП: Т]**
Основное уравнение (нелинейная логистическая форма):
```
dH/dt = α(1 − C)H − βC·H² + ξ(t)
```
где:
- `H` — энтропия биосистемы (безразмерная, нормированная),
- `C ∈ [0,1]` — когерентность внимания,
- `α` — коэффициент прироста энтропии при C = 0,
- `β` — коэффициент негэнтропийного эффекта,
- `ξ(t)` — стохастический член.

**Обоснование нелинейности.** При H → 0 рост замедляется (нет энтропии для генерации), при H → ∞ член `−βC·H²` ограничивает рост. Это устраняет тривиальность линейной модели. Стационарное решение: `H* = α(1−C)/(βC)` при `ξ = 0`.

### 2.3. Критическое значение когерентности

**#WFS-ЦМ-ТЕП-008 [ТИП: Т]**
Критическое значение: `C* = α/(α+β)`. При C > C* энтропия убывает. Для α = 0.8, β = 0.2: C* = 0.8.

При C = C* система в равновесии. При C < C* — деградация. При C > C* — регенерация. Порог 0.8 означает: для устойчивого снижения энтропии требуется когерентность не менее 80%.

### 2.4. Связь с термодинамикой Пригожина

**#WFS-ЦМ-ТЕП-019 [ТИП: Т]**
Уравнение ICFT — частный случай термодинамики диссипативных структур. Разложение `dS = d_eS + d_iS`, где `d_iS ≥ 0` (внутреннее производство энтропии), `d_eS` — внешний поток. Локальное снижение `dS < 0` достигается при `d_eS < −d_iS`. Роль отрицательного потока играет когерентность C.

### 2.5. Связь с теорией Ландау

**#WFS-ЦМ-ТЕП-020 [ТИП: Т]**
Перегруппировка уравнения:
```
dH/dt = −(α+β)(C − C*)H + ξ(t)
```
Связь с теорией Ландау: Ψ — параметр порядка, C — управляющий параметр. C* — точка фазового перехода. При C > C* система переходит в упорядоченное состояние (регенерация), при C < C* — в неупорядоченное (деградация).

### 2.6. Операциональное определение C

**#WFS-ЦМ-ТЕП-057 [ТИП: Т]**
Когерентность внимания C измеряется как взвешенная сумма нормированных приборных и субъективных показателей:
```
C = w₁·R̃MSSD + w₂·H̃F + w₃·S̃EEG + w₄·P̃subj
```
где:
- R̃MSSD — нормированный RMSSD (вариабельность сердечного ритма),
- H̃F — нормированный HF-компонент,
- S̃EEG — нормированная альфа-тета синхронизация ЭЭГ,
- P̃subj — нормированная субъективная шкала (0–10),
- wᵢ = 0.25 (первое приближение).
Нормировка: `R̃ = (R − R_min)/(R_max − R_min)`.
В разделе «Обсуждение» указано, что веса могут быть уточнены эмпирически.

### 2.7. Связь Ψ и H

**#WFS-ЦМ-ТЕП-058 [ТИП: Т]**
Ψ — комплексный параметр порядка (нелокальная мера когерентности поля), H — скалярная энтропия биосистемы. Связь:
```
H(t) = H_max − (H_max − H_min)·|Ψ(t)|²
```
При |Ψ| → 1, H → H_min. При |Ψ| → 0, H → H_max.

### 2.9. Информационная гигиена питания

**#WFS-ЦМ-ТЕП-016 [ТИП: П] (редакция)**
Пища — носитель информационных вибраций (Punon). Мясная несёт информацию страха и агрессии, что увеличивает энтропию H. Вегетарианская пища, приготовленная и потреблённая с высокой когерентностью внимания (C ≥ 0.8), снижает H. Протокол: 3–12 месяцев вегетарианства до работы с полем.
