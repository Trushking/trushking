### 1.1. Кризис управления сложностью

Современная цивилизация сталкивается с парадоксом: при экспоненциальном росте вычислительных мощностей и объёмов данных эффективность управления сложными системами (от личности до государства) не превышает 5–15%. Качество решений — 2–3/5. Остальные 85–95% ресурсов расходуются на обслуживание энтропии: конфликты, переделки, бюрократию, имитацию деятельности.

### 1.3. ICFT как решение: теория единого поля сознания

Предлагается теория информационно-когерентного поля (ICFT). Сознание рассматривается как динамический параметр порядка Ψ, управляющий энтропией биосистем через когерентность внимания C.

**Основное уравнение динамики энтропии:**
```
dH/dt = α(1 − C)H − βC·H² + ξ(t)
```
где:
- H — энтропия биосистемы,
- C ∈ [0,1] — когерентность внимания (операционально измеримая величина),
- α — коэффициент прироста энтропии при C = 0,
- β — коэффициент негэнтропийного эффекта,
- ξ(t) — стохастический член.

Нелинейность (член −βC·H²) обеспечивает насыщение: при H → 0 рост замедляется, при H → ∞ ограничивается.

**Динамика Ψ:**
```
d|Ψ|/dt = λ·C·|Ψ| − μ·|Ψ|³ + η(t)
dφ/dt = ω + ν·|Ψ|²
```
Стационарная амплитуда: |Ψ|* = √(λC/μ). При C → 1: |Ψ|* → 1.

**Связь Ψ и H:**
```
H = H_max − (H_max − H_min)·|Ψ|²
```

**Порог когерентности:**
```
C*(H) = α / (α + βH)
```
При H = 1: C* = 0.8. При C > C*(H) энтропия убывает.

**Операциональное определение C:**
```
C = w₁·R̃MSSD + w₂·H̃F + w₃·S̃EEG + w₄·P̃subj
```
где wᵢ = 0.25 (первое приближение), R̃, H̃F, S̃EEG, P̃subj — нормированные показатели (ВСР, ЭЭГ, субъективная шкала).
