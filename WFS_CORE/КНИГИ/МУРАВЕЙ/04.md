# ДОПОЛНИТЕЛЬНАЯ СЦЕНА: ВОЗВРАЩЕНИЕ В РОДНОЙ МУРАВЕЙНИК — ПЕРВЫЙ КОНФЛИКТ

# ИТОГОВЫЙ ПРИНЦИП: СЛУЖЕНИЕ МНОГООБРАЗНО

Муравей не «убирает мусор» — он **служит**. Его служение — это:

- **Уборка** — чтобы было чисто и легко.
- **Помощь** — чтобы другим не было тяжело.
- **Внимание** — чтобы другие чувствовали, что их видят.
- **Забота** — чтобы слабые не были забыты.
- **Присутствие** — чтобы скорбящие не были одиноки.

- **Терпение** — чтобы конфликтные не встречали агрессии.

**И всё это — он делает для себя.** Не для того, чтобы его хвалили. Не для того, чтобы его запомнили. А для того, чтобы ему самому было светло, тепло и радостно жить на своей улице.

И эта **естественная радость** заражает других.
