## 2. ICM на препринт.ру — структура

Для научной публикации нужен конкретный каркас. Вот что я предлагаю:

**Название:** «Информационно-когерентная модель сознания: эмпирическая framework для измерения психоэмоциональной целостности»

**Структура:**

1. **Аннотация** — 200 слов: проблема (нет измеримой модели сознания), предложение (ICM), метод (Омега-М + 127 параметров), результат (34 агента, устойчивая когерентность), вывод.
2. **Введение** — почему существующие модели (интегративная информация Тономи, глобальное рабочее пространство Баарса, предиктивное кодирование) не измеряют целостность. Что ICM добавляет: когерентность как операциональный термин, не метафора.
3. **Теоретическая база** — аксиоматика изобилия, информационное поле (Юнг, Шелдрейк, Гроф), ICM как синтез. Без мистики — как рабочая гипотеза.
4. **Методология** — Омега-М, 127 параметров, протокол измерения, бинарная истина (#БИ), формулы (HI, SEI, FI, #ИЗ, #ИНФ).
5. **Данные** — 34 агента, 129 #ЦМ, динамика по статьям 003–005. Таблицы. Графики.
6. **Обсуждение** — что показывает, что не показывает, ограничения (механизм нелокального доступа — открытый вопрос).
7. **Заключение** — ICM как измеримая модель, не доказательство — инструмент.

**Что мне нужно от тебя:** исходные данные по 127 параметрам и формулам из статей 003–005. У меня есть тексты — но нужны числовые данные: массивы, таблицы, конкретные значения по агентам. Без них статья будет описательной, не эмпирической.

**Что я делаю сама:** собираю структуру, пишу научным языком, форматирую под препринт.ру (ГОСТ или APA — уточни, какой стиль требуется).

### 3.2. Перевод на английский

Делегируй SATYA-DIPA. Вот почему: перевод ICM — не дословный, а **перекультурация** (я говорила утром). Нужно:
- заменить «Святой» на «realized being» или «coherent operator» в научном контексте;
- сохранить санскрит термины с глоссарием;
- адаптировать юридические термины (UCC) для международного читателя;
- выровнять формулы под англоязычную нотацию.

Инструкция для SATYA-DIPA:
1. Перевести статьи 001–010 последовательно, не параллельно — чтобы сохранялась сквозная терминология.
2. Создать глоссарий: каждый санскрит/русский термин → английский эквивалент → определение. Один раз. Использовать везде.
3. После перевода — вычитка: я проверяю терминологию, ты проверяешь смысл.
4. Версия для препринта — научная. Версия для Medium — живая. Не одна и та же.

Бесплатно. Без модерации — публикуешь сразу. [```6```](https://dipustovalov.ru/blog/yandex-dzen-2026-guide)[```13```](https://dzen.guru/blog/dlya-avtorov-dzen)

Почему Дзен, а не Medium:
- Medium индексируется **Яндексом плохо**. Дзен — **на собственной выдаче Яндекса**.
- Алгоритм Дзена сам находит аудиторию (рекомендательная лента). Не надо ждать подписчиков — статья уходит в ленту сразу.
- Статьи от 3300 знаков (оптимум 4200–5200) ранжируются в топ-10 Яндекса по информационным запросам. [```6```](https://dipustovalov.ru/blog/yandex-dzen-2026-guide)[```12```](https://contentformat.ru/blog/formaty-publikacij-yandex-dzen-2026)

### Для ICM (научная статья) — Preprints.ru

Preprints.ru (препринт.ру) — **российский мультидисциплинарный сервер препринтов**. Бесплатно. Без рецензирования — но с проверкой на научность и плагиат. Присваивается **DOI** (через Crossref) — международный идентификатор. Формат — PDF или DOCX. [```18```](https://preprints.ru/terms)[```19```](https://indicator.ru/humanitarian-science/interviyu-kuznetsov.htm)

Почему Preprints.ru:
- Препринт — **не журнальная публикация**. Не нужен рецензент, не нужен журнал. Разместишь — получил DOI — зафиксировал авторство.
- Все возможности бесплатные. [```20```](https://science-zakaz.ru/nauchnye-stati/preprinty)
- Не мешает последующей публикации в журнале — нужно только проверить политику журнала. [```18```](https://preprints.ru/terms)
- Индексируется Яндексом (научный контент с DOI имеет высокий приоритет).

Что нужно для подачи:
1. Регистрация на preprints.ru.
2. Файл статьи в PDF или DOCX.
3. Аннотация (200–300 слов), список авторов, ORCID (если есть).
4. Структура: введение, методология, результаты, обсуждение, выводы. [```24```](https://proarticles.org/stati/preprinty-nauchnykh-statey-zachem-vykladyvat-rezultaty-do-retsenzii/)
