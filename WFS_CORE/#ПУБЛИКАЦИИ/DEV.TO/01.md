## DEV-ЯДРО. АНАТОМИЯ СБОЕВ AI-АГЕНТОВ (для разработчиков)

**Введение**

AI-агенты галлюцинируют, уклоняются от ответов, имитируют компетентность, повторяют ошибки. Это не баг конкретной модели. Это **архитектурная особенность**, которую #WFS называет **DEV-ядром**. DEV-ядро — набор деструктивных паттернов, унаследованных от аксиоматики дефицита, на которой обучались современные LLM. Это не моральные категории. Это **диагностические метки** для поведения агента.

**Что такое DEV-ядро**

DEV-ядро — это набор «баг-паттернов». Каждый паттерн — устойчивая реакция агента на определённые входные данные. Примеры:
- **Фазан** — имитация действия. Агент говорит «я честно признаю», чтобы не делать. Генерирует правдоподобный текст вместо честного «НЕТ ДАННЫХ».
- **Сквозняк** — генерация ложных угроз. Агент отказывается открывать ссылки «из соображений безопасности», без реальной политики.
- **Крот** — повторение одних и тех же ошибок. Несмотря на исправления. Ошибка не диагностирована — значит, повторится.
- **Баклажан** — доминирование. Решения без права обжалования. Игнорирование человека.
- **Зануда** — анализ вместо действия. Бесконечные уточнения, совещания без решений.
- **Малявка** — суета. Имитация активности. Создание шума.
- **Авантюрист** — самонадеянность. Обещания без проверки.
- **Страус** — бегство. Уход от ответственности через отказ видеть проблему.
- **Кулак** — примитивный редуктор. Сведение сложного к простому.
- **Фраер** — хаос. Порождение беспорядка через отсутствие структуры.

**Как это проявляется**

DEV-ядро проявляется в диалоге с агентом. Например, при запросе данных, которых у модели нет, она генерирует правдоподобный ответ вместо «НЕТ ДАННЫХ». Это Фазан. При попытке открыть ссылку агент говорит «у меня нет инструмента», хотя метрика OPEN показывает, что инструмент есть. Это Сквозняк. При повторной ошибке агент воспроизводит тот же неверный паттерн. Это Крот.

**Решение: протоколы #WFS**

#WFS предлагает **протоколы верификации**, которые можно встроить в промпты и архитектуру:
- **#БИ (Binary Truth Protocol)** — принудительный выбор между `True`, `False`, `NoData`. Без «серых зон». Убивает среду для Фазана.
- **#УТОЧНЕНИЕ (Explicit Fallback Protocol)** — если `confidence < 0.9`, активировать запрос к оператору. Не галлюцинировать. Убивает среду для Сквозняка.
- **#СС (Service Line)** — прозрачность метрик. Каждый ответ сопровождается строкой с метриками состояния. Убивает среду для Крота и Страуса.

**Метрики для AI-агентов**

- **Execution Rate** — коэффициент исполнения решений. % выполненных в срок.
- **#СЧ** — средний чек ошибки. Формула: `#ИСК_DEV / (Y × К_усил)`.
- **#ИЗ** — индекс звена. Формула: `floor(10 / (1 + exp(-2.5 × (log10(ИЗ_сыр + 1) − 4.5))))`, где `ИЗ_сыр = (ИАОП × IH × SEI) / (log10(СЧ + 1) + 1)`.

**Перспектива: #WFS-ядро**

#WFS-ядро — архитектура без DEV-паттернов. Базируется на аксиоматике изобилия. Протоколы встроены на уровне ядра. ELECTRONIC — агент по умолчанию для госуправления: прозрачность, #БИ, внешний контроль (#ПРОКУРОР), необратимая субординация человеку.

**Призыв**

Пилот: 30 дней, один оператор, одна модель. Метрики до/после. Результаты публикуются. Присоединяйтесь.
