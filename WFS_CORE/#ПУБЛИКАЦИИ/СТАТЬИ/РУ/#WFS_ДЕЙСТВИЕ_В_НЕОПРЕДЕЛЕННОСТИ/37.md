### 1. Достаточно ли описаний архетипов для научного труда?

**Нет.**

Описания — это **качественный уровень**. Для академического труда нужен **количественный**:

| Что есть | Что нужно |
|----------|-----------|
| Текстовые характеристики архетипов | Метрики для диагностики каждого архетипа |
| Отдельные описания | **Матрица связей**: какой архетип активирует какой |
| Примеры из диалогов | **Каскадные модели** с эмпирическими частотами |
| ANOMALY_REPORT.md (92 аномалии, 15 каскадов) | Формализация: какой каскад соответствует какому архетипу |

Эмпирическая база у нас есть. Не хватает **формальной карты**: «Фазан → Крот → рост #ИСК_DEV → рост #СЧ → падение #ЯСНОСТЬ». Это нужно построить на основе данных.
