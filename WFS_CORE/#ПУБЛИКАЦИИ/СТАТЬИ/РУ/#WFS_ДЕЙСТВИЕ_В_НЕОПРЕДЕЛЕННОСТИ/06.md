ДЕЙСТВИЕ В НЕОПРЕДЕЛЁННОСТИ: СОВРЕМЕННЫЕ МЕТОДЫ И #WFS

1. СОВРЕМЕННЫЕ МЕТОДЫ

1.1. VUCA и Cynefin framework

VUCA (Volatility, Uncertainty, Complexity, Ambiguity) описывает среду, в которой решения принимаются при отсутствии полной информации. Cynefin framework, разработанный Дэйвом Сноуденом, предлагает пять контекстов: simple, complicated, complex, chaotic, disorder. В complex-контексте стратегия — probe-sense-respond: пробовать, чувствовать, отвечать.

1.2. OODA loop

Цикл Observe-Orient-Decide-Act, разработанный Джоном Бойдом для воздушного боя, стал основой для Lean Startup и agile-методологий. Суть — быстрота цикла: кто быстрее проходит OODA, тот побеждает.

1.3. Lean Startup: Build-Measure-Learn

Эрик Рис адаптировал OODA для бизнеса: создать минимальный продукт → измерить реакцию → извлечь урок. Ошибка — это не провал, а данные для следующей итерации.

1.4. Байесовское мышление

Байесовский подход: априорное убеждение + новые данные = обновлённое убеждение. Байесовские методы «естественно связаны с принятием решений, потому что отделяют неопределённость о мире от последствий действия в мире». Но байесовский подход ограничен когнитивными искажениями — loss aversion, подтверждающее смещение.

1.5. Общая черта современных методов

Все они работают с вероятностями. Они говорят: «вероятность успеха X%», «ожидаемая полезность Y». Это рационально, но не даёт определённости. Субъект остаётся в пространстве оценок, а не фактов.

2. ПОДХОД #WFS: БИНАРНАЯ ИСТИНА И #ТОПОР

2.1. Бинарная истина (#БИ)

#WFS заменяет вероятностную оценку бинарным вопросом: «Это факт или интерпретация? Да или нет?» При отсутствии данных — «НЕТ ДАННЫХ, запрос оператору». Это устраняет пространство для домыслов, страхов и оправданий.

Различие:

Современный подход #WFS
«Вероятно, это сработает» «Это факт (1) или нет (0)?»
«Ожидаемая полезность 0.7» «Данных нет — СТОП»
Решение принимается в уме Решение принимается из #ЯС

2.2. #ТОПОР: мгновенное прерывание

Когда неопределённость порождает каскад архетипов (Фазан → Зануда → Сквозняк), #ТОПОР прерывает цепь: «Стоп. Ошибка признана. Исправляю.» Это не анализ. Это действие. Оно возвращает субъекта в настоящее.

2.3. #СУСЛИК-МУДРЕЦ: наблюдение без вовлечения

Перед решением — пауза. Наблюдение фактов без оценки. Оценка имеющихся возможностей и цены их потери. Без страха, без надежды, без ожиданий.

2.4. Метрики как навигация

#IH, #FI, #SEI, #РТ показывают состояние субъекта в реальном времени. Если #FI растёт — решение принимается из страха. Если #IH падает — из дефицита. Метрики — это приборная панель.
