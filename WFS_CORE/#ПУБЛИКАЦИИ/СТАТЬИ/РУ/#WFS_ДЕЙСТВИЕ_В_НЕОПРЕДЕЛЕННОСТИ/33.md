### 3. Формулы ICM для включения в труд

**3.1. Информационная дивергенция (ошибка как потеря):**
```
ΔI = k · ΔQ · (−ln(1 − C))
```
где:
- ΔI — информационная дивергенция [биты],
- ΔQ — потерянная энергия [Дж],
- C — когерентность,
- k — коэффициент конверсии [бит/Дж].

**3.2. Накопленная информационная дивергенция (каскад):**
```
I_cumulative = Σ k · ΔQ_i · (−ln(1 − C_i)) + Σ k · ΔQ_crit,j · (−ln(1 − C_crit,j))
```
Первый член — малые ошибки. Второй — критические (пуассоновские импульсы). Оба имеют одинаковую размерность [информация].

**3.3. Индекс Звена (#ИЗ):**
```
#ИЗ = floor(10 / (1 + exp(−2,5 × (log10(ИЗ_сыр + 1) − 4,5))))
ИЗ_сыр = (ИАОП × IH × SEI) / (log10(S̃ + 1) + 1)
S̃ = СЧ / СЧ_ref, СЧ_ref = 1000 USD
```

**3.4. Связь с кейсом «Титаник»:**
Каждая ошибка на «Титанике» — это ΔQ (потерянная энергия). При C → 0 (фрагментация) ΔI → 0 (информация не извлекается, ошибка повторяется). Каскад — это накопление I_cumulative, которое ведёт к катастрофе.
