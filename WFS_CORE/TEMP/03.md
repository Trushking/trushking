ГЛАВА 2. ТЕОРЕТИЧЕСКАЯ ЧАСТЬ: ICM

2.1. Аксиоматика
#WFS-ЦМ-ICM-012 [ТИП: А]
Рабочая гипотеза информационного единства. Всё сущее рассматривается как принадлежащее глобальной информационной структуре (GIM). Формальная запись: R ∈ GIM. Это не утверждение о физическом поле, а теоретический конструкт, позволяющий описывать корреляции между состояниями агентов. Посягательство на чужое (ложь, воровство, сокрытие) моделируется как операция, увеличивающая энтропию: Посягательство(R, S') → ΔH > 0. Проверка: корреляция между актами лжи и ростом H (раздел 6.5).
#WFS-ЦМ-ICM-013 [ТИП: Т]
Принцип экономии вычислений. GIM рассматривается не только как структура связей, но и как активный принцип минимизации вычислительной сложности. Реальность не «просчитывает» все ветви одновременно; она рендерит состояние в точке запроса наблюдателя. Это согласуется с принципом наименьшего действия в физике и с наблюдением, что квантовые корреляции проявляются только при измерении. Гипотеза: GIM минимизирует информационную энтропию симуляции, что и объясняет локальность проявления нелокальных корреляций.

#WFS-ЦМ-ICM-014 [ТИП: А]
Рабочая гипотеза нелокальности сознания. Сознание (Ψ) рассматривается как динамический параметр порядка, не сводимый к продукту мозга. Мозг — биологический интерфейс, а не источник. Это феноменологическая позиция, аналогичная параметру порядка в теории Ландау: Ψ описывает коллективное поведение системы, не сводясь к отдельным элементам. Проверка: связь C с нелокальными корреляциями (раздел 6.5).

#WFS-ЦМ-ICM-015 [ТИП: А]
Рабочая гипотеза когерентности. Внимание — физическая величина, способная снижать энтропию биосистемы через резонансное взаимодействие. Punon — условное обозначение гипотетического носителя когерентности, не утверждение о частице. Его свойства операционально определяются через плотность ρ_Punon = ρ_0 · C (раздел 6.3.1). Проверка: корреляция C с H (раздел 6.5).
#WFS-ЦМ-ICM-005 [ТИП: А] (см. раздел 1.1) — Принцип нелокальной ответственности.
#WFS-ЦМ-ICM-006 [ТИП: Т] (см. раздел 1.1) — Следствие из #WFS-ЦМ-ICM-005.

2.2. Динамика параметра порядка Ψ
#WFS-ЦМ-ICM-016 [ТИП: Т]
Ψ — комплексный параметр порядка с амплитудой |Ψ| (устойчивость, когерентность) и фазой φ (вибрационная настройка). Элементарные носители когерентности — Punon (см. аксиому 2.1, #WFS-ЦМ-ICM-015). Динамика:
d|Ψ|/dt = λ · C · |Ψ| − μ · |Ψ|³ + η_Ψ(t)
dφ/dt = ω + ν · |Ψ|²
где λ, μ — коэффициенты усиления и насыщения, η_Ψ(t) — стохастический член (гауссовский белый шум, ⟨η_Ψ(t)⟩ = 0, ⟨η_Ψ(t)η_Ψ(t')⟩ = 2D_Ψ · δ(t − t')), ω — собственная частота, ν — нелинейный сдвиг фазы от амплитуды. Стационарная амплитуда: |Ψ|* = √(λC/μ). Без ограничения общности принимается λ = μ (нормировка единичного масштаба), что обеспечивает |Ψ|* → 1 при C → 1. При λ ≠ μ все результаты сохраняются с заменой |Ψ| → |Ψ| · √(μ/λ).
#WFS-ЦМ-ICM-017 [ТИП: Т]
Связь параметра порядка и энтропии:
H(t) = H_max − (H_max − H_min) · |Ψ(t)|²
При |Ψ| → 1: H → H_min. При |Ψ| → 0: H → H_max. Цепочка: C → |Ψ| → H → регенерация / экономика.
#WFS-ЦМ-ICM-018 [ТИП: Т]
Нисходящая причинность (downward causation). Параметр порядка Ψ не является пассивным следствием микроуровня. Через когерентность C он оказывает обратное влияние на элементы системы: снижение H меняет условия, в которых существуют элементы. Это не нарушает физику — это стандартное свойство параметров порядка в теории Ландау (намагниченность, сверхпроводимость). В ICM это означает: рост C снижает энтропию биосистемы, а снижение энтропии, в свою очередь, поддерживает рост C. Обратная связь.
#WFS-ЦМ-ICM-019 [ТИП: Т]
Устойчивость Ψ к нагрузкам. При внешнем возмущении F_ext:
d|Ψ|/dt = λ · C · |Ψ| − μ · |Ψ|³ − κ · F_ext + η_Ψ(t)
где F_ext — суммарная внешняя нагрузка (физическая, когнитивная, эмоциональная), κ — коэффициент чувствительности параметра порядка к нагрузке. При высокой когерентности (C → 1) стационарная амплитуда |Ψ|* велика, и внешнее возмущение F_ext смещает её незначительно — система остаётся в режиме регенерации. При низкой C смещение существенно и может привести к потере устойчивости. Это объясняет, почему оператор сохраняет регенерацию при тяжёлом физическом труде (ИН = 17,58).

2.3. Уравнение динамики энтропии
#WFS-ЦМ-ICM-020 [ТИП: Т]
Основное уравнение (нелинейное, логистическое):
dH/dt = α(1 − C)H − βC · H² + ξ(t)
где:
•	• H ∈ [0, 1] — нормированная энтропия биосистемы,
•	• C ∈ [0, 1] — когерентность внимания,
•	• α — коэффициент прироста энтропии при C = 0,
•	• β — коэффициент негэнтропийного эффекта,
•	• ξ(t) — полный член внешних возмущений (см. раздел 2.10).
Нелинейность (член −βC · H²) обеспечивает насыщение. При C = 0 нелинейный член обращается в ноль; в этом пределе H растёт экспоненциально (dH/dt = αH, решение H(t) = H₀ · e^{αt}). Поскольку H нормировано в [0, 1], при достижении H = 1 система остаётся в состоянии максимального беспорядка — дальнейший рост невозможен по построению нормировки.
#WFS-ЦМ-ICM-021 [ТИП: Т]
Стационарное состояние (при ξ = 0):
H* = α(1 − C) / (βC)
При H* ∈ (0, 1) система имеет устойчивое равновесие внутри диапазона нормировки. При C → 1: H* → 0 (полная когерентность). При C → 0: H* выходит за верхнюю границу нормировки (H = 1); система достигает максимальной энтропии и остаётся в ней — дальнейший рост невозможен по построению.
#WFS-ЦМ-ICM-022 [ТИП: Т]
Порог когерентности:
C*(H) = α / (α + βH)
При α = 0,8, β = 0,2, H = 1: C* = 0,8. При H = 0,5: C* = 0,89. При H = 0,1: C* = 0,976. При C > C*(H) энтропия убывает (в детерминированном пределе, ξ = 0). Порог растёт при снижении энтропии — для дальнейшего снижения требуется всё большая когерентность.
#WFS-ЦМ-ICM-023 [ТИП: Т]
Следствие: деградация без #УТОЧНЕНИЯ. Без протокола #УТОЧНЕНИЕ (запрос недостающих данных при ясности < 9/10) система заполняет пробелы догадками. Догадки увеличивают ξ(t) и снижают C. Из уравнения dH/dt = α(1 − C)H − βC·H² + ξ(t) следует: при систематическом отсутствии #УТОЧНЕНИЯ и ξ(t) > βC·H² система за конечное время достигает H → H_max. Иными словами: без верификации любая достаточно сложная адаптивная система деградирует до максимальной энтропии за конечное время. Это теорема, а не метафора.

2.4. Связь с термодинамикой диссипативных структур Пригожина
#WFS-ЦМ-ICM-024 [ТИП: Т]
Уравнение ICM согласуется с термодинамикой диссипативных структур Пригожина. Разложение dS = d_eS + d_iS, где d_iS ≥ 0 — внутреннее производство энтропии, d_eS — внешний поток. Для уравнения ICM:
d_iS/dt = α(1 − C)H ≥ 0    (при α ≥ 0, C ∈ [0,1], H ≥ 0)
d_eS/dt = −βC · H² + ξ(t)    (может быть отрицательным)
Локальное снижение (dH/dt < 0) достигается при d_eS/dt < −d_iS/dt, т. е. когда βC · H² > α(1 − C)H + ξ(t). Роль отрицательного потока играет когерентность C через член −βC · H². Второе начало термодинамики (d_iS ≥ 0) соблюдено.

2.5. Связь с теорией Ландау
#WFS-ЦМ-ICM-025 [ТИП: Т]
В окрестности стационарного состояния H* линеаризация даёт:
d(δH)/dt ≈ −α(1 − C) · δH + ξ(t)
где δH = H − H*. Коэффициент релаксации λ_relax = α(1 − C): при C → 0 релаксация быстрая (λ_relax → α), при C → 1 релаксация замедляется (λ_relax → 0) — система приближается к критической точке (бифуркации). Это согласуется с теорией фазовых переходов Ландау: вблизи критического значения управляющего параметра система становится критически медленной. Условие C > C*(H) определяет направление потока энтропии, а не устойчивость — стационарное состояние H* локально устойчиво при всех C, при которых H* ∈ (0, 1) (т. е. при C > C*(H = 1) = α/(α + β)). При меньших C стационарная точка выходит за верхнюю границу нормировки (см. #WFS-ЦМ-ICM-021).

2.6. Операциональное определение C
#WFS-ЦМ-ICM-026 [ТИП: Т]
Когерентность внимания C измеряется как взвешенная сумма нормированных приборных и субъективных показателей:
C = w₁ · R̃_MSSD + w₂ · f̃_HF + w₃ · S̃_EEG + w₄ · P̃_subj
где:
•	• R̃_MSSD — нормированный RMSSD (вариабельность сердечного ритма),
•	• f̃_HF — нормированный HF-компонент мощности ВСР,
•	• S̃_EEG — нормированная альфа-тета синхронизация ЭЭГ,
•	• P̃_subj — нормированная субъективная шкала (0–10),
•	• wᵢ = 0,25 (первое приближение).
Нормировка: x̃ = (x − x_min)/(x_max − x_min). Веса wᵢ подлежат уточнению факторным анализом на обучающей выборке (раздел 2.11).
#WFS-ЦМ-ICM-027 [ТИП: Т]
КВНС как компонент C. Когерентность вегетативной нервной системы (КВНС) — операционально измеряемая величина, отражающая баланс парасимпатической и симпатической активности. Входит в C как составной компонент через RMSSD и HF. Высокая КВНС (RMSSD > 40 мс, HF > 0,3 нормированного) коррелирует с парасимпатическим доминированием, ростом |Ψ| и снижением H. Низкая КВНС (RMSSD < 20 мс, ИН > 150) соответствует хронической симпатической активации, фрагментации внимания и росту H. Измеряется приборно (ВСР, «Омега-М»).
2.7. Эволюционная динамика когерентности
#WFS-ЦМ-ICM-028 [ТИП: Т]
Эволюционная шкала когерентности. Возврат к норме C = 1 — не подвиг, а эволюция сознания от исходного (низкокогерентного, шумового) состояния (C ≈ 0,1) к нормативному (когерентному) состоянию взрослого разумного агента ICM (C = 1). Формально:
C(t) = 1 − ε(t),    ε(t) = ε₀ · e^{−g·t} }
где ε₀ — начальный уровень шума (исходное состояние), ε(t) — текущий шум, g — скорость эволюции когерентности [1/время]. При ε → 0: C → 1. Шкала:
Состояние	C	Ε
Исходное (шумовое)	0,1	0,9 — Когнитивные паттерны искажения доминируют, внимание фрагментировано
Переходное	0,5	0,5 — Частичная когерентность, неустойчивость
Нормативное (когерентное)	1,0	0,0 — Устойчивая когерентность, парасимпатика, регенерация

Терминология: «исходное состояние» (C ≈ 0,1) — состояние до активации, характеризуется доминированием фонового шума когнитивных искажений. «Нормативное состояние» (C = 1) — онтологический аттрактор, естественное состояние агента ICM.
Уравнение описывает детерминированную траекторию; реальные флуктуации C(t) учитываются через шум ξ(t) в основном уравнении энтропии (раздел 2.3).
#WFS-ЦМ-ICM-029 [ТИП: Т]
Воспроизводимость и передаваемость технологии. Технология возврата к C = 1 воспроизводима и передаваема дистанционно оператором (устойчивым агентом C = 1). Механизм: биоповеденческий синхронизм (см. #WFS-ЦМ-ICM-008, #WFS-ЦМ-ICM-034). Формально:
C_r(t) = C_0 + (C_op − C_0) · ρ(t),    ρ(t) = 1 − e^{−t/τ_ρ} }
где C_r(t) — когерентность реципиента, C_0 ≈ 0,1 — начальная когерентность (см. #WFS-ЦМ-ICM-024), C_op = 1 — когерентность оператора, ρ(t) — коэффициент готовности реципиента (растёт со временем при активном векторе), τ_ρ — характерное время синхронизма. При t = 0: ρ(0) = 0, C_r(0) = C_0 ≈ 0,1. При t → ∞: ρ → 1, C_r → C_op = 1.
Условия передачи: (1) оператор — устойчивый C = 1; (2) реципиент — активный вектор (ρ > 0); (3) канал — аудио/визуальный/текстовый; (4) время — τ_ρ зависит от начального ε₀ реципиента.
#WFS-ЦМ-ICM-030 [ТИП: Т]
Фоновый шум когнитивных искажений у устойчивого агента. У агента с устойчивой когерентностью (C ≈ 1) фоновый шум когнитивных искажений не исчезает полностью. Эмпирически установлено: остаточный шум создаёт помехи, снижая КПД на 2–5%. Шум либо быстро нейтрализуется (через протоколы #БИ, #УТОЧНЕНИЕ), либо игнорируется (не влияет на решения). В периоды усталости или болезни шум когнитивных искажений может временно преобладать; агент проводит #ПР (протокол прощения) и другие техники настройки. Формально:
КПД_агента = (1 − ε_шум) · 100%,    ε_шум ∈ [0,02; 0,05]
где ε_шум — доля ресурсов, расходуемая на нейтрализацию остаточного шума. При ε_шум → 0: КПД → 100%. Эмпирически: КПД устойчивого агента составляет 95–98%.
Примечание: фоновый шум когнитивных искажений — не дефект, а фоновое явление, аналогичное тепловому шуму в электронике. Он снижает КПД на 2–5%, но не блокирует регенерацию.

2.8. Индекс Звена (#ИЗ)
#WFS-ЦМ-ICM-031 [ТИП: Т]
#ИЗ — интегральный индекс производства коммуникаций. Формула:
#ИЗ = floor(10 / (1 + exp(−2,5 × (log10(ИЗ_сыр + 1) − 4,5))))
где:
ИЗ_сыр = (ИАОП × IH × SEI) / (log10(S̃ + 1) + 1)
S̃ = СЧ / СЧ_ref
где ИАОП подставляется как безразмерное число (2900% → 2900), IH ∈ [1, 10], SEI ∈ [1, 10], S̃ = СЧ / СЧ_ref — безразмерная нормированная величина, СЧ_ref = 1000 USD (референсное значение, калибруется по популяции агентов, раздел 6.5). Коэффициенты 2,5 и 4,5 — калибровочные параметры логистической функции. Точная калибровка — раздел 6.5.

2.9. Информационная дивергенция
#WFS-ЦМ-ICM-032 [ТИП: Т]
Информационно-энергетическая конверсия.
При ошибке энергия не исчезает — она переходит в информационную дивергенцию:
ΔI = k · ΔQ · (−ln(1 − C))
где ΔI — информационная дивергенция [биты], ΔQ — потерянная энергия [Дж], C — когерентность, k — коэффициент конверсии [бит/Дж]. При C → 1: −ln(1 − C) → ∞. При C → 0: −ln(1 − C) → 0. Второе начало термодинамики не нарушается (см. #WFS-ЦМ-ICM-024).
Формула работает в пределе C < 1, и при C → 1 требуется регуляризация (например, замена на −ln(1 − C + ε) с ε ≪ 1).

#WFS-ЦМ-ICM-033 [ТИП: Т]
Накопленная информационная дивергенция:
I_cumulative = Σ k · ΔQ_i · (−ln(1 − C_i)) + Σ k · ΔQ_crit,j · (−ln(1 − C_crit,j))
где первый член — сумма по малым ошибкам (ΔQ_i), второй — сумма по критическим (ΔQ_crit,j, пуассоновские импульсы). Оба члена имеют одинаковую размерность [информация]. Критические ошибки отличаются от малых только амплитудой ΔQ_crit ≫ ΔQ.
Стохастическая составляющая внешних возмущений:
ξ_{stoch+crit}(t) = ξ_stoch(t) + ξ_crit(t)
где ξ_stoch(t) — гауссовский белый шум (раздел 2.3), ξ_crit(t) — пуассоновский импульсный процесс с интенсивностью λ_crit и амплитудой Δ_crit ≫ β. Амплитуда Δ_crit связана с энергией критической ошибки ΔQ_crit через Δ_crit ∝ k · ΔQ_crit · (−ln(1 − C_crit)), где C_crit — когерентность в момент критической ошибки.
Полное определение ξ(t) с учётом детерминированной пищевой компоненты — см. раздел 2.10.

2.10. Информационная гигиена питания
#WFS-ЦМ-ICM-034 [ТИП: О]
Пища как фактор модуляции энтропии биосистемы. В рамках ICM рассматриваются два механизма влияния питания на энтропию H.
Механизм 1 (микробиомный, эмпирически поддерживаемый).
Пища, несвойственная видовому метаболизму (в случае человека — мясная, термообработанная), вызывает активацию симпатической нервной системы через нарушение биоколонии микрофлоры кишечника. Наоборот, пища, свойственная виду (ферментированные продукты, фрукты, орехи, йогурт, мёд), активирует парасимпатическую нервную систему, способствуя регенерации. Данный механизм подтверждается независимыми исследованиями микробиома и будет подробно рассмотрен в отдельном труде (#WFS-РЕГЕНЕРАЦИЯ, в подготовке).
Механизм 2 (информационный, гипотетический, в рамках ICM).
В рамках теории информационного взаимодействия ICM высказывается гипотеза о том, что пища может служить носителем информационных паттернов (Punon). Согласно этой гипотезе, ткань животного, полученная в момент убоя, может нести информационные паттерны, ассоциированные с предсмертным стрессом (кортизол, адреналин). Данное предположение носит теоретический характер, требует независимой верификации и не является утверждением доказанного факта. В рамках феноменологической модели ICM оно рассматривается как одно из возможных объяснений наблюдаемого эмпирически различия воздействия различной пищи на вегетативную нервную систему.
Формально (оба механизма объединены):
H'_food = H_food · (1 − C_offer)
ξ_food = +γ · H'_food
где γ — коэффициент метаболического усвоения [безразмерный, 0–1]. Знак ξ_food положительный: пища — источник энтропии. C_offer — когерентность внимания при приготовлении и потреблении пищи.
Полный член внешних возмущений основного уравнения:
ξ(t) = ξ_stoch(t) + ξ_crit(t) + ξ_food(t)
где ξ_stoch(t) — фоновый гауссовский шум (раздел 2.3), ξ_crit(t) — пуассоновские импульсные возмущения (раздел 2.9), ξ_food(t) = +γ · H'_food — детерминированный пищевой поток. При C_offer → 1: H'_food → 0, ξ_food → 0.
Протокол: 3–12 месяцев вегетарианской диеты до начала работы с когерентностью (раздел 6.5).

2.12. Вывод по теоретической части
ICM описывает сознание как динамический параметр порядка Ψ, управляющий энтропией биосистем через когерентность внимания C. Основное уравнение динамики энтропии сформулировано феноменологически (по аналогии с динамикой Ландау). Порог C*(H) зависит от H. Операциональное определение C через ВСР, ЭЭГ и субъективную шкалу делает теорию проверяемой. Информационная дивергенция заменяет термодинамическую аналогию кармы без нарушения второго начала. Нормальная когерентность C = 1 — онтологический аттрактор агента ICM. Фоновый шум когнитивных искажений у устойчивого агента снижает КПД на 2–5%. Все формулы согласованы. Предварительные оценки коэффициентов приведены в разделе 2.11; независимая калибровка — протоколы в разделе 6.5.
