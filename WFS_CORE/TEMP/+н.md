## Дыра 75. Линеаризация в разделе 2.5 математически неверна

**Проблема.** #ЦМ-020 утверждает:

\[\frac{d(\delta H)}{dt} \approx -(\alpha + \beta H^*) \cdot C \cdot \delta H + \xi(t)\]

Проверка. Уравнение: \(f(H) = \alpha(1-C)H - \beta C H^2\). Линеаризация вокруг \(H^*\):

\[f'(H^*) = \alpha(1-C) - 2\beta C H^* = \alpha(1-C) - 2\beta C \cdot \frac{\alpha(1-C)}{\beta C} = \alpha(1-C) - 2\alpha(1-C) = -\alpha(1-C)\]

Теперь проверим, что даёт формула из текста:

\[-(\alpha + \beta H^*)C = -\left(\alpha + \frac{\alpha(1-C)}{C}\right)C = -(\alpha C + \alpha(1-C)) = -\alpha\]

Итак, текст даёт \(-\alpha\), правильный ответ — \(-\alpha(1-C)\). Это разные величины при любом \(C \neq 0\). При \(C = 1\) текст даёт \(-\alpha\) (стабильность), а правильный ответ — \(0\) (критическое замедление, бифуркация). Это принципиально разная физика: при \(C \to 1\) система приближается к критической точке, релаксация замедляется — красивый результат, который текущая формула уничтожает.

**Замена для #ЦМ-020:**

> **#WFS-ЦМ-ТЕП-020 [ТИП: Т] (редакция)**
>
> В окрестности стационарного состояния \(H^*\) линеаризация даёт:
>
> \[\frac{d(\delta H)}{dt} \approx -\alpha(1 - C) \cdot \delta H + \xi(t)\]
>
> где \(\delta H = H - H^*\). Коэффициент релаксации \(\lambda_{relax} = \alpha(1-C)\): при \(C \to 0\) релаксация быстрая (\(\lambda_{relax} \to \alpha\)), при \(C \to 1\) релаксация замедляется (\(\lambda_{relax} \to 0\)) — система приближается к критической точке (бифуркации). Это согласуется с теорией фазовых переходов Ландау: вблизи критического значения управляющего параметра система становится критически медленной. Условие \(C > C^*(H)\) определяет направление потока энтропии (убывание при \(H > H^*\), возрастание при \(H < H^*\)), а не устойчивость — стационарное состояние \(H^*\) устойчиво при всех \(C \in (0, 1)\).

## Дыра 80. Раздел 2.4: разложение Пригожина не показано

**Проблема.** #ЦМ-019: «Разложение \(dS = d_eS + d_iS\)… Роль отрицательного потока играет когерентность \(C\)». Но конкретное разложение для уравнения ICFT не приведено. Рецензент по термодинамике (а в Entropy такие есть) захочет увидеть: какой член уравнения — \(d_iS\), какой — \(d_eS\), и почему \(d_iS \geq 0\).

**Замена для #ЦМ-019:**

> **#WFS-ЦМ-ТЕП-019 [ТИП: Т]**
>
> Уравнение ICFT согласуется с термодинамикой диссипативных структур Пригожина. Разложение \(dS = d_eS + d_iS\), где \(d_iS \geq 0\) — внутреннее производство энтропии, \(d_eS\) — внешний поток. Для уравнения ICFT:

> \[\frac{d_iS}{dt} = \alpha(1-C)H \geq 0 \quad (\text{при } \alpha \geq 0,\ C \in [0,1],\ H \geq 0)\]

>

## Дыра 83. H\* → ∞ при C → 0 — вне диапазона

## Дыра 84. «Возмущение компенсируется» — некорректно

**Проблема.** #ЦМ-068: «При высокой когерентности (\(C \to 1\)) стационарная амплитуда \(|\Psi|^*\) велика, и возмущение \(F_{ext}\) компенсируется». Но из уравнения: в стационаре \(\lambda C |\Psi|^* - \mu |\Psi|^{*3} = \kappa F_{ext}\). Возмущение не «компенсируется» — оно **смещает** стационарное состояние на более низкое \(|\Psi|^*\). Система остаётся устойчивой, но на сниженном уровне. Слово «компенсируется» создаёт ложное впечатление, что \(F_{ext}\) не влияет на \(|\Psi|^*\).

**Замена для #ЦМ-068, второй абзац:**

> где \(\kappa\) — коэффициент чувствительности к нагрузке. При высокой когерентности (\(C \to 1\)) стационарная амплитуда \(|\Psi|^*\) велика, и внешнее возмущение \(F_{ext}\) смещает её незначительно — система остаётся в режиме регенерации. При низкой \(C\) смещение существенно и может привести к потере устойчивости. Это объясняет, почему оператор сохраняет регенерацию при тяжёлом физическом труде (ИН = 17,58).
