## Дыра 64. «Отражающая граница» без механизма

**Проблема.** Раздел 1.3: при \(C = 0\) «\(H\) ограничивается верхней границей нормировки \(H = 1\) (отражающая граница)». Но в уравнении \(dH/dt = \alpha H\) нет механизма, удерживающего \(H \leq 1\) — решение экспоненциально растёт и превышает 1. «Отражающая граница» постулируется, но не выводится из уравнения. Рецензент спросит: что именно отражает?

**Латка.** Уточнить: граница — свойство определения \(H\) как нормированной величины, не свойство уравнения.

**Замена для абзаца о C = 0:**

> При \(C = 0\) нелинейный член обращается в ноль; в этом пределе \(H\) растёт экспоненциально (\(dH/dt = \alpha H\), решение \(H(t) = H_0 \cdot e^{\alpha t}\)). Поскольку \(H\) по определению нормировано в \([0, 1]\), при достижении \(H = 1\) система остаётся в состоянии максимального беспорядка — дальнейший рост невозможен по построению нормировки, а не по динамике уравнения. Для описания перехода через границу \(H = 1\) в будущих работах может быть добавлен независимый насыщающий член \(-\gamma H^2\) с \(\gamma \ll \beta\).
