## Дыра 50. Насыщение не работает при C = 0 — математическое противоречие

**Проблема.** Раздел 1.3 заявляет: «Нелинейность (член \(-\beta C \cdot H^2\)) обеспечивает насыщение: при \(H \to 0\) рост замедляется, при \(H \to \infty\) ограничивается». Но при \(C = 0\) нелинейный член обращается в ноль: \(-\beta \cdot 0 \cdot H^2 = 0\). Уравнение принимает вид \(dH/dt = \alpha H + \xi(t)\) — экспоненциальный рост без насыщения. Утверждение «при \(H \to \infty\) ограничивается» **неверно при \(C = 0\)**. При этом \(H\) заявлено как \(H \in [0, 1]\) — но без механизма ограничения \(H\) может превысить 1.

**Латка.** Добавить насыщающий член, не зависящий от C, либо квалифицировать область применимости.

**Замена для абзаца о нелинейности (раздел 1.3, после уравнения dH/dt):**

> Нелинейность (член \(-\beta C \cdot H^2\)) обеспечивает насыщение роста энтропии при \(C > 0\): при \(H \to 0\) скорость роста замедляется, при больших \(H\) член \(-\beta C H^2\) доминирует и ограничивает рост. При \(C = 0\) нелинейный член обращается в ноль; в этом пределе \(H\) растёт линейно по скорости \(\alpha H\) и ограничивается верхней границей нормировки \(H = 1\) (отражающая граница). Физически это означает: при полной фрагментации (\(C = 0\)) система быстро достигает максимального беспорядка и остаётся в нём. Для описания перехода через границу \(H = 1\) в будущих работах может быть добавлен независимый насыщающий член \(-\gamma H^2\) с \(\gamma \ll \beta\).
