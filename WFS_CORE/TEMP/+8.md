## Дыра 193. «Третье начало термодинамики не нарушается» — без обоснования

**Проблема.** #ЦМ-033: формула ΔI = k · ΔQ · (−ln(1−C)), затем: «Третье начало термодинамики не нарушается.» — утверждение без единого слова объяснения. Третье начало (тепловая теорема Нернста) говорит: S → 0 при T → 0. Связь между формулой информационной дивергенции и третьим началом не очевидна и не объяснена. Рецензент-физик спросит: при чём здесь третье начало?

**Замена — убрать или объяснить:**

Вариант A (убрать):

> При C → 1: −ln(1−C) → ∞ (малая ошибка даёт большой долг). При C → 0: −ln(1−C) → 0.

Вариант B (объяснить):

> При C → 1: −ln(1−C) → ∞ (малая ошибка даёт большой долг — высококогерентный агент имеет больше «порядка», и его потеря дороже). При C → 0: −ln(1−C) → 0 (некогерентный агент уже находится в максимуме энтропии, ошибки не увеличивают её дополнительно). Это согласуется с термодинамической аналогией: диссипация тем больше, чем дальше система от равновесия (Пригожин, см. раздел 2.4).

## Дыра 198. Формула ΔI: при C = 0 ошибки «бесплатны» — контринтуитивно

**Проблема.** Формула ΔI = k · ΔQ · (−ln(1−C)). При C = 0: ΔI = 0 — ошибки некогерентного агента не создают информационной дивергенции. Но глава 5 (#ЦМ-066) предупреждает: «ущерб здоровью, финансовые потери, деградация отношений» — именно для **неподготовленного** (некогерентного) исследователя. Получается: формула говорит «ошибки бесплатны при C ≈ 0», а текст главы — «ошибки опасны именно при C ≈ 0».

Это не обязательно ошибка — можно интерпретировать так: ΔI измеряет **долг перед полем**, а не прямой ущерб. Некогерентный агент уже в максимуме энтропии, его ошибки не увеличивают долг — но прямой ущерб (здоровью, финансам) происходит через другие механизмы. Однако без явного объяснения рецензент увидит противоречие формулы и текста.

**Замена — добавить пояснение после формулы:**

> Формула описывает **долг перед полем** (информационную дивергенцию), а не прямой ущерб агенту. Некогерентный агент (C ≈ 0) уже находится в максимуме энтропии — его ошибки не увеличивают ΔI, но приводят к прямому ущербу через обычные физические и социальные механизмы (#ЦМ-066). Когерентный агент (C → 1) имеет больше «порядка» — и его потеря дороже: малая ошибка создаёт большой информационный долг.
