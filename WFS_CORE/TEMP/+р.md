## Дыра 34. λ = μ влечёт α = β — противоречие с α = 0,8, β = 0,2

**Проблема.** В разделе 1.3 заявлено:
- α = 2λ(H\_max − H\_min), β = 2μ(H\_max − H\_min)
- λ = μ (нормировка)
- α = 0,8, β = 0,2 (для C\* = 0,8)

Если λ = μ, то α = β. Но α = 0,8 ≠ 0,2 = β. Противоречие. Более того, при α = β получаем C\* = α/(α + β) = 0,5, а не 0,8. Вся числовая иллюстрация C\* = 0,8 рушится.

**Латка.** Отказаться от утверждения, что dH/dt алгебраически выведен из dΨ/dt. Оба уравнения — феноменологические, мотивированные одной физикой (динамика Ландау), но точная алгебраическая связь между (α, β) и (λ, μ) нетривиальна и в данной работе не выводится. Параметры α и β определяются эмпирически.

**Замена для раздела 1.3, три абзаца начиная с «Динамика Ψ»:**

> **Динамика Ψ.** Первичным динамическим уравнением ICFT является уравнение эволюции параметра порядка:
>
> \[\frac{d|\Psi|}{dt} = \lambda C |\Psi| - \mu |\Psi|^3 + \eta(t)\]
>
> \[\frac{d\varphi}{dt} = \omega + \nu |\Psi|^2\]
>
> где \(\lambda, \mu\) — коэффициенты усиления и насыщения, \(\eta(t)\) — стохастический член (гауссовский белый шум, \(\langle\eta(t)\rangle = 0\), \(\langle\eta(t)\eta(t')\rangle = 2D_\Psi \delta(t - t')\)), \(\omega\) — собственная частота, \(\nu\) — нелинейный сдвиг фазы. Стационарная амплитуда: \(|\Psi|^* = \sqrt{\lambda C / \mu}\). Без ограничения общности принимается \(\lambda = \mu\) (нормировка единичного масштаба), что обеспечивает \(|\Psi|^* \to 1\) при \(C \to 1\).
>
> **Связь Ψ и H.** Энтропия \(H\) — наблюдаемая величина, алгебраически связанная с параметром порядка:
>
> \[H(t) = H_{max} - (H_{max} - H_{min}) \cdot |\Psi(t)|^2\]
>
> При \(|\Psi| \to 1\): \(H \to H_{min}\). При \(|\Psi| \to 0\): \(H \to H_{max}\).
>
> **Уравнение для dH/dt.** Практическое уравнение динамики энтропии формулируется феноменологически — по аналогии с динамикой Ландау, но как самостоятельное уравнение для наблюдаемой величины:
>
> \[\frac{dH}{dt} = \alpha(1 - C)H - \beta C H^2 + \xi(t)\]
>
> где:
> - \(H \in [0, 1]\) — нормированная энтропия биосистемы (\(H = (S - S_{min})/(S_{max} - S_{min})\), где \(S\) — термодинамическая энтропия),
> - \(C \in [0, 1]\) — когерентность внимания (операционально измеримая величина),
> - \(\alpha\) — коэффициент прироста энтропии при \(C = 0\),
> - \(\beta\) — коэффициент негэнтропийного эффекта,
> - \(\xi(t)\) — стохастический член (гауссовский белый шум, \(\langle\xi(t)\rangle = 0\), \(\langle\xi(t)\xi(t')\rangle = 2D\delta(t - t')\), \(D \ll \alpha\)).
>
> Параметры \(\alpha\) и \(\beta\) не выводятся напрямую из \(\lambda\) и \(\mu\): точная алгебраическая связь зависит от деталей проекции \(|\Psi| \to H\) и в данной работе не конкретизируется. Оба уравнения — феноменологические, описывающие один и тот же физический процесс на разных уровнях описания: уравнение для \(\Psi\) — на уровне параметра порядка, уравнение для \(H\) — на уровне наблюдаемой величины.
