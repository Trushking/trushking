## Дыра 54. «Растёт линейно» — но рост экспоненциальный

**Проблема.** Раздел 1.3, абзац «Нелинейность и насыщение»: «При C = 0 нелинейный член обращается в ноль; в этом пределе H **растёт линейно по скорости** αH». Но \(\frac{dH}{dt} = \alpha H\) — это **экспоненциальный** рост, не линейный. Решение \(H(t) = H_0 e^{\alpha t}\). «Линейно» означает \(\frac{dH}{dt} = \text{const}\), а здесь \(\frac{dH}{dt}\) пропорционально \(H\). Рецензент-математик споткнётся.

**Латка.** Заменить «линейно» на «экспоненциально».

**Замена:**

> При `C = 0` нелинейный член обращается в ноль; в этом пределе `H` растёт экспоненциально (\(\frac{dH}{dt} = \alpha H\), решение \(H(t) = H_0 e^{\alpha t}\)) и ограничивается верхней границей нормировки `H = 1` (отражающая граница). Физически это означает: при полной фрагментации (`C = 0`) система быстро достигает максимального беспорядка и остаётся в нём. Для описания перехода через границу `H = 1` в будущих работах может быть добавлен независимый насыщающий член `−γH²` с `γ ≪ β`.
