## Дыра 23. Редундантность: три уравнения для двух переменных

**Проблема.** В разделе 1.3 введены одновременно: (1) уравнение для \(dH/dt\), (2) уравнение для \(d|\Psi|/dt\), (3) алгебраическая связь \(H = H_{max} - (H_{max} - H_{min})|\Psi|^2\). Если \(H\) алгебраически определяется через \(|\Psi|\), то \(dH/dt\) — не независимое уравнение, а следствие динамики \(\Psi\): \(dH/dt = -2(H_{max}-H_{min})|\Psi| \cdot d|\Psi|/dt\). Но \(dH/dt = \alpha(1-C)H - \beta C H^2\) и это следствие — разные выражения. Они совместимы только при жёстком соотношении между \((\alpha, \beta)\) и \((\lambda, \mu)\), которое нигде не дано. Рецензент увидит: либо одно уравнение лишнее, либо система переопределена.

**Латка.** Чётко разделить: уравнение для \(\Psi\) — первичное (феноменологическое), связь \(H(|\Psi|)\) — определение, а уравнение для \(dH/dt\) — статистическая проекция динамики \(\Psi\) на наблюдаемую \(H\) в пределе усреднения.

**Замена для раздела 1.3, абзац «Динамика Ψ» и последующий:**

> **Динамика Ψ.** Первичным динамическим уравнением ICFT является уравнение эволюции параметра порядка:
>
> \[\frac{d|\Psi|}{dt} = \lambda C |\Psi| - \mu |\Psi|^3 + \eta(t)\]
>
> \[\frac{d\varphi}{dt} = \omega + \nu |\Psi|^2\]
>
> где \(\lambda, \mu\) — коэффициенты усиления и насыщения, \(\eta(t)\) — стохастический член (гауссовский белый шум, \(\langle\eta(t)\rangle = 0\), \(\langle\eta(t)\eta(t')\rangle = 2D_\Psi\delta(t-t')\)), \(\omega\) — собственная частота, \(\nu\) — нелинейный сдвиг фазы. Стационарная амплитуда: \(|\Psi|^* = \sqrt{\lambda C / \mu}\). При \(\lambda = \mu\) и \(C \to 1\): \(|\Psi|^* \to 1\).
>
> **Связь Ψ и H.** Энтропия \(H\) — наблюдаемая величина, алгебраически связанная с параметром порядка:
>
> \[H(t) = H_{max} - (H_{max} - H_{min}) \cdot |\Psi(t)|^2\]
>
> При \(|\Psi| \to 1\): \(H \to H_{min}\). При \(|\Psi| \to 0\): \(H \to H_{max}\).
>
> **Уравнение для dH/dt** как проекция динамики Ψ. Усредняя по быстрым флуктуациям \(\eta(t)\) и линеаризуя связь \(H(|\Psi|)\) в окрестности стационарной точки, получаем:
>
> \[\frac{dH}{dt} = \alpha(1 - C)H - \beta C H^2 + \xi(t)\]
>
> где \(\alpha = 2\lambda(H_{max} - H_{min})\), \(\beta = 2\mu(H_{max} - H_{min})\), \(\xi(t)\) — эффективный шум, индуцированный \(\eta(t)\). Таким образом, уравнение для \(H\) — не независимый постулат, а статистическая проекция первичной динамики \(\Psi\) на наблюдаемую энтропию. Нелинейность \(-\beta C H^2\) наследуется от кубического члена \(-\mu|\Psi|^3\) в уравнении Ландау.
