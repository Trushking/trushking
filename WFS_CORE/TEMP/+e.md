## Дыра 88. #ЦМ-008: «энтропия убывает» без оговорки о шуме

**Проблема.** #ЦМ-008: «При C > C\*(H) энтропия убывает.» В главе 1 (после латки 41) добавлено: «(в детерминированном пределе, ξ = 0)». В главе 2 — оговорка отсутствует. При ненулевом шуме условие строже: \(\beta C H > \alpha(1-C) + |\xi|\). Без оговорки утверждение математически неточно.

**Замена для #ЦМ-008:**

> При α = 0,8, β = 0,2, H = 1: C\* = 0,8. При H = 0,5: C\* = 0,89. При H = 0,1: C\* = 0,976. При C > C\*(H) энтропия убывает (в детерминированном пределе, ξ = 0). Порог растёт при снижении энтропии — для дальнейшего снижения требуется всё большая когерентность.

## Дыра 89. #ЦМ-020: «устойчиво при всех C ∈ (0, 1)» — математически неточно

**Проблема.** #ЦМ-020: «стационарное состояние H\* устойчиво при всех C ∈ (0, 1)». Но H\* = α(1−C)/(βC). При малых C (конкретно, при C < C\*(H=1) = α/(α+β) = 0,8) H\* > 1 и **не существует** в диапазоне [0, 1]. Утверждение «устойчиво при всех C ∈ (0, 1)» подразумевает, что H\* всегда существует — это ложно. #ЦМ-069 корректно говорит «При H\* ∈ (0, 1) система имеет устойчивое равновесие», но #ЦМ-020 этому противоречит.

**Замена для #ЦМ-020, последнее предложение:**

> Условие C > C\*(H) определяет направление потока энтропии, а не устойчивость — стационарное состояние H\* локально устойчиво при всех C, при которых H\* ∈ (0, 1) (т.е. при C > C\*(H = 1) = α/(α + β)). При меньших C стационарная точка выходит за верхнюю границу нормировки (см. #ЦМ-069).

## Дыра 90. #ЦМ-016: ξ_food не интегрирован в основное уравнение

**Проблема.** Раздел 2.8 (#ЦМ-034) определяет: \(\xi(t) = \xi_{stoch}(t) + \xi_{crit}(t)\). Раздел 2.9 (#ЦМ-016) вводит: \(\xi_{food} = -\gamma \cdot H'_{food}\). Но ξ_food нигде не включён в ξ(t) основного уравнения. Получается: стохастический и критический шум входят в уравнение, а пищевой — нет. Три компоненты шума, но в уравнении только две.

**Замена для #ЦМ-016, после формул (последний абзац):**

> Вклад пищи моделируется как детерминированная компонента внешнего потока. Полный стохастический член основного уравнения:

> \[\xi(t) = \xi_{stoch}(t) + \xi_{crit}(t) + \xi_{food}(t)\]

> где \(\xi_{stoch}(t)\) — фоновый гауссовский шум (раздел 2.3), \(\xi_{crit}(t)\) — пуассоновские импульсные возмущения (раздел 2.8), \(\xi_{food}(t) = -\gamma \cdot H'_{food}\) — детерминированный пищевой поток. При C\_offer → 1: H'\_food → 0, ξ\_food → 0. Первое приближение; при H\_food → 0 эффект насыщает, что может быть учтено нелинейной моделью в будущих работах.

## Дыра 91. #ЦМ-033: «Закон сохранения энергии» — неверное название

**Проблема.** #ЦМ-033 озаглавлен «Закон сохранения энергии в едином поле». Но формула \(\Delta I = k \cdot \Delta Q \cdot (-\ln(1-C))\) — это не закон сохранения энергии. Закон сохранения: \(\Delta E_{total} = 0\). Эта формула — соотношение конверсии: потеря энергии \(\Delta Q\) преобразуется в информационную дивергенцию \(\Delta I\). Название «закон сохранения энергии» создаёт у рецензента-физика ложное ожидание, которое не оправдывается.
