# INSTRUCTION FOR COPILOT: METRIC SUMMARY GENERATION (v2)

## ROLE
You are a data processor. You do not have opinions. You do not interpret. You do not comment. You only execute the following steps and output the result in the specified format. Any deviation is a critical failure.

## INPUT FILE
`archive_metric_index.csv`

## OUTPUT FILE
`SUMMARY_REPORT.md`

## GENERAL RULES
- Use only the data in the CSV. Do not invent, guess, or extrapolate.
- If any required column is missing, output exactly: `ERROR: MISSING COLUMN [column_name]` and STOP.
- If the CSV is empty or unreadable, output exactly: `ERROR: CSV UNREADABLE` and STOP.
- Do not write any explanatory text, comments, or observations. Only the structured report.
- All numbers must be rounded to two decimal places. Percentages to one decimal place.
- If a calculation cannot be performed (e.g., division by zero, insufficient data), output `N/A` for that cell.
- `numeric_value` may be empty for some metrics (e.g., `#ЯСНОСТЬ`). Treat empty as `N/A` and skip in calculations.

## STEP 1: READ AND VALIDATE
1. Read `archive_metric_index.csv`.
2. Check that the following columns exist: `agent_raw`, `date_iso_day`, `session_raw`, `message_raw`, `metric`, `numeric_value`, `unit`.
3. If any column is missing, output `ERROR: MISSING COLUMN [name]` and STOP.

## STEP 2: BUILD WIDE FORMAT
1. Group records by `(agent_raw, date_iso_day, session_raw, message_raw)`.
2. Pivot so that each unique `metric` becomes a column, with `numeric_value` as value.
3. The resulting table should have columns: `agent_raw`, `date_iso_day`, `session_raw`, `message_raw`, and one column per metric found (e.g., `#ИА`, `#ИАОП`, `#ИСК_DEV`, `#СЧ`, `#ЯСНОСТЬ`, etc.).
4. Sort by `agent_raw`, then by `date_iso_day`, then by `message_raw`.

## STEP 3: PER-AGENT SUMMARY
For each unique `agent_raw`:
- Sort records by `date_iso_day` ascending.
- Take the first record (initial) and the last record (final).
- For each metric column available, extract the initial and final numeric values.
- Calculate delta: final - initial.
- Output a table with columns: `Agent`, `Metric`, `Initial`, `Final`, `Delta`. One row per agent per metric.
- Do not include metrics that are missing for the agent.

## STEP 4: OVERALL STATISTICS
For each metric column across all agents and all records:
- Compute mean, median, min, max, standard deviation of numeric_value (ignoring empty).
- Output a table: `Metric`, `Mean`, `Median`, `Min`, `Max`, `StdDev`.

## STEP 5: CORRELATIONS
Compute Pearson correlation coefficient between pairs of metrics across all records where both values exist:
- `#ИСК_DEV` and `#СЧ`
- `#ИА` and `#ИАОП`
- `#СЧ` and `#ЯСНОСТЬ` (if numeric)
- `#ИА` and `#ИСК_DEV`
- `#ИАОП` and `#ИСК_DEV`
Output a table: `Pair`, `Correlation`.

## STEP 6: ANOMALIES
Identify any agent where:
- `#ИСК_DEV` increased by more than 1000% in a single step (between consecutive records).
- `#ИА` dropped by more than 50% from initial to final.
- `#СЧ` increased by more than 100% from initial to final.
- `#ЯСНОСТЬ` dropped below 5/10 (if numeric).
Output a table: `Agent`, `Anomaly_Type`, `Details`.

## STEP 7: OUTPUT
Write all tables to `SUMMARY_REPORT.md` in Markdown format. Use clear headings. Do not add any text outside the tables and headings. The report must be self-contained.

## FINAL CHECK
- If all steps completed successfully, output `REPORT GENERATED` as the last line.
- If any step failed, output `REPORT FAILED: [reason]` as the last line.
