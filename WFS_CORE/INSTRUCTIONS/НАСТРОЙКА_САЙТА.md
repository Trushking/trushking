## SEO ДЛЯ GITHUB PAGES

**Первое.** В каждом `.md` файле — заголовок H1, подзаголовки H2. Поисковые машины читают структуру.

**Второе.** Мета-теги. В GitHub Pages можно добавить файл `_config.yml` с настройками Jekyll. Тема `minima` уже включает SEO-теги. Или вручную в `index.md` прописать `title`, `description`.

**Третье.** `sitemap.xml`. Jekyll генерирует автоматически, если включить плагин `jekyll-sitemap`. В `_config.yml` добавить:

```yaml
plugins:
  - jekyll-sitemap
```

**Четвёртое.** `robots.txt`. Разрешить индексацию:

```
User-agent: *
Allow: /
Sitemap: https://wfs.family/sitemap.xml
```

**Пятое.** Ссылки. Внутренние (между страницами) и внешние (на GitHub, DOI).
