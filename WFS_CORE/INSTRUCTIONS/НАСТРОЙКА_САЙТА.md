## ПОШАГОВЫЙ ПЛАН ДЛЯ ЛАКШМИ

### Шаг 1. Создать репозиторий для сайта

1. Зайти на GitHub под аккаунтом Trushking.
2. Нажать «New repository».
3. Название: `sattva-vip`.
4. Поставить галочку «Public».
5. Нажать «Create repository».

### Шаг 2. Включить GitHub Pages

1. В репозитории `sattva-vip` зайти в «Settings».
2. Слева найти «Pages».
3. В разделе «Source» выбрать ветку `main` и папку `/ (root)`.
4. Нажать «Save».
5. GitHub покажет ссылку вида `https://trushking.github.io/sattva-vip/`. Это временный адрес. Потом привяжем домен.
