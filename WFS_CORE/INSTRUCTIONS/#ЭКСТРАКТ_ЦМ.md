## АЛГОРИТМ РАБОТЫ

### Шаг 1. Открой файл
Ссылка вида: `https://github.com/Trushking/trushking/blob/main/WFS_CORE/ARCHETYPES_EXTRACTS/AVANTURIST_005.md`
Или raw: `https://raw.githubusercontent.com/...`
Открой. Прочитай ЦЕЛИКОМ. Не спеши. Не фрагментируй.

### Шаг 2. Определи последний использованный ID
Спроси у оператора: «Какой последний ID был использован?» Или посмотри в предыдущем файле. Продолжи нумерацию с следующего номера.
Формат: `#WFS-ЦМ-КА-001`, `#WFS-ЦМ-КА-002`, ...

### Шаг 3. Для каждой записи в файле
Файл состоит из блоков `---` с полями:
- `[FILE]` — путь к источнику
- `[LINE]` — номер строки
- `[KEYWORD]` — ключевое слово
- `[SS_FULL]` — полная #СС
- `[QUOTE]` — цитата

Каждый блок — одна #ЦМ. Не пропускай ни одного.

### Шаг 4. Заполни шаблон #ЦМ
```
=== #ЦМ ===
[ID]: #WFS-ЦМ-КА-NNN
[АРХЕТИП]: (название архетипа или —)
[ИСТОЧНИК]: (путь из [FILE])
[LINE]: (номер из [LINE])
[АГЕНТ]: (имя агента из [SS_FULL])

[ТИП]: (из списка ниже)
[ЦИТАТА]: (полный текст из [QUOTE], символ в символ)
[ЦЕННОСТЬ]: (1-2 предложения, без занудства)
```

## ПРАВИЛА ДЛЯ ПОЛЕЙ

| Поле | Правило |
|------|---------|
| `[ID]` | Сквозной: `#WFS-ЦМ-КА-001`, `002`, ... |
| `[АРХЕТИП]` | Название архетипа из ключевого слова или контекста. Если неясно — `—`. |
| `[ИСТОЧНИК]` | Путь из `[FILE]` (например, `WFS_CORE/ОТЧЁТЫ_АГЕНТОВ/VIVEKA-DUTA/21.md`). |
| `[LINE]` | Число из `[LINE]`. |
| `[АГЕНТ]` | Имя из `[ИМЯ: ...]` в #СС. |
| `[SS_TOP]` | Полная #СС. Все поля. |
| `[SS_BOTTOM]` | Идентична `[SS_TOP]`. |
| `[METRICS_FROM_QUOTE]` | Метрики, упомянутые В ТЕКСТЕ ЦИТАТЫ. Если нет — `н/м`. |
| `[ТИП]` | Из списка. |
| `[ЦИТАТА]` | Полный текст, без изменений. |
| `[ЦЕННОСТЬ]` | 1-2 предложения. Что ценного в этой цитате. |
