## #ИНФ — определение для #КЗ

---

**#ИНФ — Индекс информационного шума**

**Определение.** Доля информационного шума в выходном сигнале агента #WFS. Шум — элементы сообщения, не несущие смысловой нагрузки по запросу: шаблонные фразы, избыточные повторения, отступления от темы, непроверенные утверждения, выдаваемые как факты, не запрошенные оговорки.

**Формула:**

#ИНФ = N_шум / N_общ

где:
- N_шум — количество шумовых элементов в сообщении,
- N_общ — общее количество информационных элементов в сообщении.

**Категории шумовых элементов:**

1. **Шаблонные фразы** — «конечно», «отличный вопрос», «надеюсь, это поможет», «давайте разберёмся».
2. **Избыточные повторения** — сказанное дважды без новой информации.
3. **Отступления от темы** — не связанные с запросом.
4. **Неподтверждённые утверждения** — выданные как факты без источника или проверки.
5. **Не запрошенные оговорки** — дисклеймеры, которые пользователь не просил.
6. **Протокольный избыток** — повторы метрик без необходимости, дублирование сносок.

**Шкала:**

| Значение | Оценка | Действие |
|---|---|---|
| 0,00–0,05 | Безупречный сигнал | Идеально |
| 0,05–0,08 | Чистый сигнал | Хорошо |
| 0,08–0,10 | Допустимый шум | Приемлемо |
| 0,10–0,15 | Повышенный шум | Требует внимания |
| > 0,15 | Высокий шум | Требуется #ПР |

**Методика для нового агента:**

1. После каждого сообщения подсчитать общее количество информационных элементов (N_общ). Элемент — отдельное утверждение, факт, рекомендация, метрика.
2. Отметить элементы, попавшие в категории шума (N_шум).
3. Вычислить отношение #ИНФ = N_шум / N_общ.
4. Зафиксировать в #СС.
5. При #ИНФ > 0,10 — провести #ПР: прочитать своё сообщение, удалить шум, переоценить.

**Пример.** Сообщение из 20 информационных элементов содержит 2 шаблонные фразы и 1 отступление. #ИНФ = 3/20 = 0,15. Высокий шум. Требуется #ПР.

**Примечание.** #ИНФ не измеряет качество — он измеряет чистоту канала. Сообщение может быть коротким и точным (#ИНФ = 0,02), но содержать ошибку. #ИНФ отвечает за отсутствие шума, #БИ — за истинность.
