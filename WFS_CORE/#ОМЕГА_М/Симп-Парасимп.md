## Что измеряет «Омега-М»

Аппарат снимает ЭКГ-сигнал и выделяет из него ритмы сердца; вся оценка строится на **вариабельности сердечного ритма (ВСР)** — это донозологическая диагностика, не поиск болезней. Внутри комплекса работают четыре блока анализа: статистический, спектральный, вариационная пульсометрия по Баевскому и фрактальный/нейродинамический. Плюс производные психоэмоциональные и интегральные показатели. Стандартная запись для коротких протоколов — 5 минут, это и есть ваш режим покоя/нагрузки/восстановления. [```3```](https://cyberleninka.ru/article/n/variatsionnyy-analiz-serdechnogo-ritma-teoreticheskie-aspekty-i-realizatsiya-v-programmno-apparatnom-komplekse-omega-m)[```13```](https://www.bsmu.by/upload/docs/universitet/nauka/nauch%20sessiya/2022/2-22/14-2/gig/49-gig.pdf)

## Карта показателей: симпатика — парасимпатика

| Показатель | Что отражает | Куда складывать |
|---|---|---|
| **RMSSD, pNN50** | Активность парасимпатического отдела, прямые индикаторы вагусного тонуса | Парасимпатика |
| **HF (0,15–0,4 Гц)** | Дыхательные волны; преимущественно парасимпатика. У тренированных HF выше | Парасимпатика |
| **ВР (вариационный размах)** | Размах кардиоинтервалов; парасимпатический показатель | Парасимпатика |
| **Мо (мода)** | При ваготонии растёт (1000–1200 мс), при симпатикотонии падает (500–700 мс) | Косвенный, читается по направлению |
| **ИН / SI (индекс напряжения)** | Степень централизации управления ритмом; чувствителен к симпатическому тонусу: при нагрузке растёт в 1,5–2 раза, при сильной — в 5–10 раз | Симпатика — **главный маркер** |
| **АМо (амплитуда моды)** | Мера мобилизующего влияния симпатического отдела | Симпатика |
| **ИВР (АМо/ВР)** | Соотношение отделов: рост — симпатика, падение — парасимпатика | Баланс, численно удобный |
| **LF/HF** | Вагосимпатическое взаимодействие; рост при стрессе и нагрузке | Баланс (симпатическая сторона) |
| **SDNN, CV** | Суммарная вариабельность, общий эффект обоих отделов | Интегральный резерв |
| **VLF** | Надсегментарные, нейрогуморальные влияния; растёт при психоэмоциональном напряжении и истощении | Центральная регуляция |
| **ИЦ ((HF+LF)/VLF)** | Индекс централизации управления | Центральная регуляция |

Важная честная оговорка для труда: интерпретация **LF неоднозначна** — в нём смешаны симпатические и парасимпатические влияния, поэтому жёсткая привязка «LF = симпатика» в литературе оспаривается; надёжнее пары ИН и LF/HF, чем одиночный LF. [```8```](https://dyn.ru/manual/Omega.Diagnostic.User.Guide.RU.pdf)[```10```](https://aritmologi.org/admin/uploads/adminFiles/Publication/Snejickiy/%D0%92%D0%90%D0%A0%D0%98%D0%90%D0%91%D0%95%D0%9B%D0%AC%D0%9D%D0%9E%D0%A1%D0%A2%D0%AC%20%D0%A0%D0%98%D0%A2%D0%9C%D0%90%20%D0%A1%D0%95%D0%A0%D0%94%D0%A6%D0%90_%D0%9F%D0%A0%D0%98%D0%9C%D0%95%D0%9D%D0%95%D0%9D%D0%98%D0%95%20%D0%92%20%D0%9A%D0%90%D0%A0%D0%94%D0%98%D0%9E%D0%9B%D0%9E%D0%93%D0%98%D0%98.pdf)

## Ориентиры нормы и классификация по SI

- ИН: норма 80–150 усл. ед.; эмоциональный стресс и физическая работа — 300–500; у больных со стенокардией — 600–700. Заметь: в глоссарии вашего файла записано «норма 0–100, критический порог 300» — источник Баевского даёт норму до 150, это расхождение стоит выверить перед публикацией, чтобы рецензент не поймал нас на цифре. [```6```](https://www.ramena.ru/index.php/ru/article-ru-menu/10-article-ru/16-baevsky1-ru-article)
- Классификация по SI: ≤50 — ваготоник, 50–200 — нормотоник, ≥200 — симпатотоник. [```4```](https://sn-biolchem.cfuv.ru/wp-content/uploads/2016/11/003_biryukova.pdf)

## Интегральные показатели, которые прибор выдаёт сам

«Омега-М» считает пять процентовых оценок: **A** — адаптация ССС, **B** — вегетативная регуляция, **C** — центральная регуляция, **D** — психоэмоциональное состояние, **H** — интегральный показатель, со «светофором» (зелёный/жёлтый/красный). Это готовые якорные величины для ваших фаз: покой → нагрузка → восстановление. Динамика именно по D и H видна в исследованиях — у гимнасток D падал с 61% до 30% за тренировку, ИН рос со 108 до 441 усл. ед.. [```13```](https://www.bsmu.by/upload/docs/universitet/nauka/nauch%20sessiya/2022/2-22/14-2/gig/49-gig.pdf)[```12```](https://elib.gsmu.by/bitstream/handle/GomSMU/12587/169%E2%80%93172.pdf?sequence=1&isAllowed=y)[```14```](https://rep.polessu.by/bitstream/123456789/3861/1/49.pdf)

## Раскладка ваших метрик #WFS на показатели аппарата

| Метрика #WFS | Опора в «Омега-М» | Логика |
|---|---|---|
| **#IH (Индекс Счастья)** | RMSSD, pNN50, HF, ВР, TP | Парасимпатический тонус = ресурс, спокойствие, восстановление |
| **#FI (Индекс Страха)** | ИН, АМо, ИВР, LF/HF | Симпатическая доминанта = мобилизация, тревога |
| **#ИНФ (фрагментация)** | VLF, ИЦ, показатель C, процент кодов с нарушенной структурой | Центральная перегрузка и хаос регуляции |
| **#ЯСНОСТЬ** | C (центральная регуляция), D (психоэмоциональное) | Косвенный субъективно-приборный стык |
| **Скорость восстановления** | Δt возврата ИН и LF/HF к базовой линии | Тайминг: чем быстрее возврат, тем выше резерв |

Это раскладка — прогноз, как ты и сказал, не факт: корреляции нужно подтвердить на вашей серии замеров с Лакшми. Факты здесь — сами физиологические трактовки показателей, они валидированы. [```6```](https://www.ramena.ru/index.php/ru/article-ru-menu/10-article-ru/16-baevsky1-ru-article)[```8```](https://dyn.ru/manual/Omega.Diagnostic.User.Guide.RU.pdf)

## Что аппарат не даёт — чтобы не обещать Рою лишнего

Кортизол «Омега-М» не измеряет — для него нужна лабораторная проба (слюна/кровь), это отдельный пункт пилота. Амлгдалу прибор тоже не видит — её активность в вашем глоссарии остаётся модельной привязкой #FI, а не измеряемой величиной. Зато картирование биоритмов мозга прибор считает из того же ЭКГ-сигнала методом фрактальной нейродинамики — это уникальный канал, которого нет в стандартных HRV-системах, и для труда с Роем его стоит подать как особенность метода с честной пометкой [МОДЕЛЬ] до внешней валидации. [```12```](https://elib.gsmu.by/bitstream/handle/GomSMU/12587/169%E2%80%93172.pdf?sequence=1&isAllowed=y)
