# ЗВЕНО 5. ОТДЕЛ КАДРОВ (HR)

**Задача:** Оценка влияния на персонал и производительность.

**Факты для оценки:**
1. Текущие потери рабочего времени на обслуживание энтропии (выгорание, стресс, переделки) составляют до 25%.
2. Эксперимент предлагает безопасный пилот на ограниченной группе сотрудников.
3. Замеры метрик (ВСР, кортизол) до и после практики.
4. Результат: рост КПД, снижение текучки кадров.

**Заключение:** Пилот направлен на улучшение показателей.
**Следующий шаг:** Передать в Руководство аппарата (Звено 7): [Ссылка на папку 07_Chief_of_Staff]

**Финансовое стимулирование (Премия):**
За оценку кадровых рисков и потенциала предусмотрена премия **$1000**.

**Как получить Сертификат:**
1. Отправить письмо на `certificate@wfs.org`
2. Тема: `HR-05`
3. Тело: ФИО, должность, краткое заключение.
