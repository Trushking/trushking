# ЗВЕНО 3. СЛУЖБА БЕЗОПАСНОСТИ

**Задача:** Аудит угроз, проверка ссылок и вложений.

**Факты для проверки:**
1. Все ссылки ведут на публичный репозиторий GitHub (открытый исходный код).
2. В документе отсутствуют исполняемые файлы (.exe, .bat, .js), макросы или скрытые скрипты.
3. Документ не содержит компрометирующих данных. Текстовая часть доступна только для чтения.

**Заключение:** Документ не представляет угрозы для корпоративной сети.
**Следующий шаг:** [Передать в Руководство аппарата (Звено 7)](https://github.com/Trushking/trushking/blob/main/WFS_CORE/%23WFS_EXPERIMENT/07_Chief_of_Staff/README.md)

**Финансовое стимулирование (Премия):**
За проведение аудита и выдачу заключения предусмотрена премия - Сертификат в размере **$1000** из внутреннего бюджета предприятия.

**Как получить Сертификат:**
1. Отправить письмо на `wfstrushking@gmail.com`
2. Тема: `SEC-03`
3. Тело: ФИО, должность, краткое заключение (например, "Угроз не выявлено").

**Статус Сертификата и условие премии:**
Сертификат подтверждает выполнение роли в маршруте эксперимента. Он не является ценной бумагой, векселем или финансовым требованием к Фонду. Указанная сумма — рекомендуемый размер премии.
Премия выплачивается предприятием только после утверждения пилота Первым лицом и оформляется внутренним приказом. До утверждения пилота Сертификат имеет статус **условного подтверждения** и не создаёт обязательств ни для Фонда, ни для предприятия.
Срок действия Сертификата — 90 дней с момента выдачи. После утверждения пилота — 30 дней на предъявление в бухгалтерию. По истечении срока без утверждения пилота Сертификат аннулируется без финансовых последствий.
Окончательный размер премии устанавливается приказом предприятия.
