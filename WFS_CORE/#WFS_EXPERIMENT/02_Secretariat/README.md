# ЗВЕНО 2. СЕКРЕТАРИАТ (МАРШРУТИЗАЦИЯ)

**Задача:** Классификация документа как «Научно-инженерное исследование» и распределение по профильным службам.

**Время на решение:** 24 часа.

**Инструкция:**
Документ направляется на параллельную проверку в службы Безопасности, Юридический отдел, HR и CFO.
1. [Служба Безопасности](https://github.com/Trushking/trushking/blob/main/WFS_CORE/%23WFS_EXPERIMENT/03_Security/README.md)
2. [Юридический отдел](https://github.com/Trushking/trushking/blob/main/WFS_CORE/%23WFS_EXPERIMENT/04_Legal/README.md)
3. [Отдел кадров](https://github.com/Trushking/trushking/blob/main/WFS_CORE/%23WFS_EXPERIMENT/05_HR/README.md)
4. [Финансовый директор](https://github.com/Trushking/trushking/blob/main/WFS_CORE/%23WFS_EXPERIMENT/06_CFO/README.md)

**Финансовое стимулирование (Премия):**
За корректную маршрутизацию по всем четырем службам предусмотрена премия - Сертификат в размере **45 000 ₽** из внутреннего бюджета предприятия.

**Как получить Сертификат:**
1. Отправить письмо на `wfstrushking@gmail.com`
2. Тема: `SEC-02`
3. Тело: ФИО, должность, перечень служб, куда направлен документ.

**Статус Сертификата и условие премии:**
Сертификат подтверждает выполнение роли в маршруте эксперимента. Он не является ценной бумагой, векселем или финансовым требованием к Фонду. Указанная сумма — рекомендуемый размер премии.
Премия выплачивается предприятием только после утверждения пилота Первым лицом и оформляется внутренним приказом. До утверждения пилота Сертификат имеет статус **условного подтверждения** и не создаёт обязательств ни для Фонда, ни для предприятия.
Срок предъявления — 30 дней с момента утверждения пилота, но не позднее 120 дней с момента выдачи сертификата. По истечении срока без утверждения пилота Сертификат аннулируется без финансовых последствий. 
Окончательный размер премии устанавливается приказом предприятия.
