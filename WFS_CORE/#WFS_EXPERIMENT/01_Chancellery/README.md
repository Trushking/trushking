# ЗВЕНО 1. КАНЦЕЛЯРИЯ (ПЕРВИЧНЫЙ ВХОД)

**Задача:** Регистрация входящего документа и передача в Секретариат.
**Время на решение:** 24 часа.

**Инструкция:**
1. Зарегистрировать входящий номер документа.
2. Перейти по ссылке следующего звена: [Ссылка на папку 02_Secretariat]

**Финансовое стимулирование (Премия):**
За корректную регистрацию и передачу документа предусмотрена премия в размере **$300** из внутреннего бюджета предприятия (перераспределенного на оптимизацию).

**Как получить Сертификат (Подтверждение):**
1. Отправить письмо на адрес: `certificate@wfs.org`
2. В теме письма указать код: `CH-01`
3. В теле письма указать: ФИО, должность, входящий номер документа.
4. В ответ придет PDF-файл с электронной подписью фонда.
5. Предъявить Сертификат в бухгалтерию или руководителю для начисления премии.
