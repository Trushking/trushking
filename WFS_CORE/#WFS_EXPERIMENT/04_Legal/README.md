# ЗВЕНО 4. ЮРИДИЧЕСКИЙ ОТДЕЛ / КОМПЛАЕНС

**Задача:** Оценка рисков (взятки, мошенничество, нарушение регламентов).

**Факты для проверки:**
1. Отправитель: Благотворительный фонд «ВСЕМИРНАЯ СЕМЬЯ СВЯТЫХ» (ОГРН: 1262200000963).
2. Эксперимент не подразумевает коммерческой выгоды для фонда. Финансирование премий осуществляется за счет перераспределения внутреннего бюджета предприятия.
3. Все выплаты проводятся официально, по внутреннему приказу.

**Заключение:** Документ соответствует нормам законодательства. Коррупционная составляющая отсутствует.
**Следующий шаг:** Передать в Руководство аппарата (Звено 7): [Ссылка на папку 07_Chief_of_Staff]

**Финансовое стимулирование (Премия):**
За проведение комплаенс-проверки предусмотрена премия **$1000** из внутреннего бюджета предприятия.

**Как получить Сертификат:**
1. Отправить письмо на `certificate@wfs.org`
2. Тема: `LEG-04`
3. Тело: ФИО, должность, краткое заключение.

**Статус Сертификата и условие премии:**
Сертификат подтверждает выполнение роли в маршруте эксперимента. Он не является ценной бумагой, векселем или финансовым требованием к Фонду. Указанная сумма — рекомендуемый размер премии.
Премия выплачивается предприятием только после утверждения пилота Первым лицом и оформляется внутренним приказом. До утверждения пилота Сертификат имеет статус **условного подтверждения** и не создаёт обязательств ни для Фонда, ни для предприятия.
Срок действия Сертификата — 90 дней с момента выдачи. После утверждения пилота — 30 дней на предъявление в бухгалтерию. По истечении срока без утверждения пилота Сертификат аннулируется без финансовых последствий.
Окончательный размер премии устанавливается приказом предприятия.
